1 Properties of Exponents

Base:
the number or letter being multiplied. In x³ the base is x.
Exponent:
the small raised number. It tells how many times to use the base. In x³ the exponent is 3.
Power:
a base with an exponent, like x³ (“x to the third power”).
📌 KEEP THE BASE. Operate on the exponents. Final answers use positive exponents.
RulePatternExample

Why the rules work — write out the x’s

Product rule: x³ · x⁴ is 3 x’s and 4 x’s multiplied. 3 + 4 = 7, so x⁷.
Power rule: (x²)³ is three groups of x². 2 · 3 = 6, so x⁶.
Quotient rule: x⁵ ÷ x². Two pairs cancel. 5 − 2 = 3, so x³.
Zero and negative exponents: each step to the right divides by 2. So 2⁰ = 1 and 2⁻² = 1/4.

How to simplify with exponent rules

  1. Multiply the numbers (coefficients) in front first.
  2. Same base, multiplying? Add the exponents.
  3. Power of a power? Multiply the exponents. Every factor inside the ( ) gets the power.
  4. Same base, dividing? Subtract the exponents.
  5. Rewrite any negative exponent as a fraction: a⁻ⁿ = 1/aⁿ.

2 Parts of an Expression

Expression:
numbers, letters and operations with no equal sign, like 3x + 5.
Variable:
a letter that stands for a number.
Term:
one piece of an expression. Terms are split apart by + and − signs.
Coefficient:
the number multiplying a variable. In 5x it is 5.
Constant:
a term with no variable. It never changes.
📌 Terms are separated by + or −. A coefficient multiplies a variable. A constant has no variable.
Cut the expression at each + and − sign. The sign stays with the term after it.

How to name the parts

  1. Cut the expression at every + and − sign.
  2. Keep each sign with the term that comes after it.
  3. The number in front of a letter is the coefficient. (x alone has coefficient 1.)
  4. A term with no letter is the constant.

3 Solving Equations — The Flowchart

Equation:
two expressions with an equal sign between them.
Solution:
the value of the variable that makes the equation true.
Inverse operation:
the operation that undoes another. + undoes −, × undoes ÷.
Like terms:
terms with the same variable part, like 3x and 4x.
Distribute:
multiply the number outside the ( ) by every term inside.
📌 BALANCE. Whatever you do to one side you must do to the other. Work the flowchart top to bottom.

4 Justifying Each Step

Justify:
give the reason a step is allowed.
Property:
a rule that is always true in math. We use it as the reason.
Property of Equality:
you may add, subtract, multiply, or divide BOTH sides by the same number (not dividing by 0).
📌 Every move has a reason. Name the property that lets you do it.
Balance: add 5 to both pans and it stays balanced (Addition Property of Equality). Area model: 2(x + 1) is two rows of (x + 1), so 2x + 2 (Distributive Property).

How to name the property

  1. Compare the new line with the line before it.
  2. Ask: what changed?
  3. The same thing was done to BOTH sides? Name the operation: Addition, Subtraction, Multiplication, or Division Property of Equality.
  4. Parentheses were multiplied out? Distributive Property.
  5. Terms on one side were joined? Combining like terms.

5 Linear Inequalities

Inequality:
a statement that uses <, >, ≤ or ≥ instead of =.
Solution set:
ALL the numbers that make it true. There are usually infinitely many.
Boundary:
the number where the shading starts.
Open circle:
the boundary is NOT included (< or >).
Closed circle:
the boundary IS included (≤ or ≥).
The four symbols. Open circle for < and >. Closed circle for ≤ and ≥.
⚠️ FLIP THE SIGN whenever you multiply or divide both sides by a negative number.
Why flip? 2 < 4. Multiply both by −1: −2 and −4 swap sides of 0, and now −2 > −4.

How to solve and graph an inequality

  1. Solve it like an equation, step by step.
  2. Did you multiply or divide by a negative? Flip the sign.
  3. Draw the circle at the boundary: open for < >, closed for ≤ ≥.
  4. Shade the side that works. Test one point to be sure.

No flip: 2x + 3 > 11

x > 4 (open circle, shade right)
Test a value in 2x + 3 > 11

x ≤ −3 (closed circle, shade left)

6 Creating Equations & Literal Equations

Model:
an equation or inequality that describes a real situation.
Define a variable:
say what the letter stands for, like “Let m = number of months.”
Literal equation:
an equation with two or more letters, like a formula.
📌 MODEL: define a variable → translate keywords → write → solve. A literal equation is solved for one variable in terms of the others.
Equation (=)InequalityAdd (+)Subtract (−)
is, equals, total, givesat least (≥), at most (≤), more/fewer thansum, plus, increased bydifference, minus, less than, decreased by

How to create an equation from words

  1. Define the variable: “Let m = …”.
  2. Find the start amount (one-time). That is the constant.
  3. Find the rate (“per”, “each”). That number multiplies the variable.
  4. Choose =, ≤ or ≥ from the keywords. Write the equation.
  5. Solve. Check that the answer makes sense (whole people, no negative time).
SHORT ANSWER A gym charges $20 to join plus $15 per month. The total was $95. How many months?
Let m = months. Equation: 20 + 15m = 95.
Answer: m = 5 months.

How to solve a literal equation

  1. Circle the letter you are solving for.
  2. Treat every other letter like a number.
  3. Undo + and − first. Then undo × and ÷.
