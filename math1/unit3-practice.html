Part B · Solving by Substitution

Solve algebraically. Type like (3,7).

B Substitution Method

1 y = 3x − 2 and y = x + 4
3x − 2 = x + 4 → 2x = 6 → x = 3. Then y = 3 + 4 = 7 → (3, 7)
2 y = −2x + 1 and 4x + y = 9
4x + (−2x + 1) = 9 → 2x + 1 = 9 → 2x = 8 → x = 4. Then y = −2(4)+1 = −7 → (4, −7)
3 x + y = 10 and y = 2x − 2
x + (2x − 2) = 10 → 3x − 2 = 10 → 3x = 12 → x = 4. Then y = 2(4) − 2 = 6 → (4, 6)

Part C · Solving by Elimination

Add or subtract to eliminate a variable. Type like (5,1).

C Elimination Method

1 x + y = 6 and 2x − y = 9
Add the equations (the y-terms cancel): 3x = 15 → x = 5. Then 5 + y = 6 → y = 1 → (5, 1)
2 3x + 2y = 0 and x − 2y = −8
Add the equations (the y-terms cancel): 4x = −8 → x = −2. Then 3(−2)+2y=0 → −6+2y=0 → y = 3 → (−2, 3)
3 2x + 3y = 12 and x + y = 5 (multiply the second equation first)
Multiply x+y=5 by −2: −2x−2y=−10. Add to 2x+3y=12: y = 2. Then x + 2 = 5 → x = 3 → (3, 2)

E One, None, or Infinite Solutions

CLASSIFY How many solutions does the system shown above have? Explain.
No solution — the lines are parallel (both have slope 2 but different y-intercepts), so they never intersect.
CLASSIFY y = 3x + 2 and 6x − 2y = −4. How many solutions does this system have? Explain.
Solving the second equation for y: −2y = −6x − 4 → y = 3x + 2, the same line as the first equation.
Infinitely many solutions — every point on the line works.
CLASSIFY y = 2x + 3 and y = −x + 9. How many solutions does this system have? Find it.
Different slopes (2 vs −1), so exactly one solution.
2x+3 = −x+9 → 3x = 6 → x = 2, y = 2(2)+3 = 7 → (2, 7).
