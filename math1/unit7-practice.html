B Factored Form ↔ Graph

1 Which factored form matches the graph shown (zeros at x = −3 and x = 1)?
✓ Setting each factor to 0 gives x = −3 and x = 1, matching the graph.
2 What are the x-intercepts (zeros) of the function graphed?
Read directly where the curve crosses the x-axis → x = −3, 1
3 Expand (x + 3)(x − 1) into standard form.
FOIL: x² − x + 3x − 3 → x² + 2x − 3
4 Using the zeros, find the vertex of the parabola. (Hint: the vertex's x-value is the midpoint of the zeros — no formula needed.)

Part C · Comparing Quadratic Functions

Function A is graphed below. Function B is given by g(x) = x² − 6x + 5.

C Graph vs. Equation

1 Function A is graphed above. Function B is g(x) = x² − 6x + 5. Which function has the greater maximum value?
✓ Function B opens upward (no maximum), so only Function A has one — 5.
2 What is the y-intercept of Function B: g(x) = x² − 6x + 5?
Plug in x=0: g(0) = 0² − 6(0) + 5 → (0, 5)
3 Find the zeros of Function B: g(x) = x² − 6x + 5.
Factor: x² − 6x + 5 = (x−1)(x−5) = 0 → x = 1, 5

Part D · Building New Functions (F-BF.1b)

Combine two functions using arithmetic operations to build a new one.

D Combining Functions

1 A rectangle has length L(x) = x + 5 and width W(x) = x. Build a new function A(x) = L(x) · W(x) for its area.
A(x) = L(x)·W(x) = (x+5)(x) = x² + 5x → A(x) = x² + 5x
2 Let f(x) = x² − 3 and g(x) = 2x + 1. Find (f + g)(x).
(f+g)(x) = (x² − 3) + (2x + 1) = x² + 2x − 2
MODEL A dropped ball's height from gravity alone is g(t) = −16t². Wind resistance adds a small constant upward drift, w(t) = 3t. Combine these to build the actual height function h(t) = g(t) + w(t).
h(t) = g(t) + w(t) = −16t² + 3t.
h(t) = −16t² + 3t — adding the two functions builds a single model for the ball's real height over time.
