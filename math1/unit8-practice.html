Part A · The Midpoint Formula & Partitioning a Segment

Type coordinates like (1,4).

A Finding the Midpoint & Partition Points

1 Find the midpoint of the segment shown, connecting (−3, 2) and (5, 6).
Midpoint = ((x1+x2)/2, (y1+y2)/2) = ((−3+5)/2, (2+6)/2) = (²⁄₂, ⁸⁄₂) → (1, 4)
2 Find the midpoint between (2, −5) and (8, 3).
Midpoint = ((2+8)/2, (−5+3)/2) = (¹⁰⁄₂, −²⁄₂) → (5, −1)
3 One endpoint of a segment is (1, 2) and the midpoint is (4, 6). Find the other endpoint.
Midpoint formula in reverse: 4 = (1+x)/2 → x=7. 6 = (2+y)/2 → y=10 → (7, 10)
4 Point P lies on segment AB, where A(−2, −4) and B(6, 4), such that AP:PB = 1:3. Find the coordinates of P.
P is 1/(1+3) = ¼ of the way from A to B.
Px = −2 + ¼(6−(−2)) = −2 + 2 = 0
Py = −4 + ¼(4−(−4)) = −4 + 2 = −2 → (0, −2)

Part B · The Distance Formula

Type the distance as a number.

B Finding the Distance

1 Find the distance between the two points shown, (1, 1) and (4, 5).
d = √[(4−1)² + (5−1)²] = √[9 + 16] = √25 → d = 5 (a 3-4-5 right triangle)
2 Find the distance between (0, 0) and (6, 8).
d = √[(6−0)² + (8−0)²] = √[36 + 64] = √100 → d = 10
3 Find the distance between (−2, 3) and (2, 0).
d = √[(2−(−2))² + (0−3)²] = √[16 + 9] = √25 → d = 5

C Comparing Slopes

1 What is true about the slopes of these two lines?
✓ Both lines have slope 3, so they are parallel.
2 What is true about the slopes of these two lines?
✓ 2 × (−½) = −1, so the lines are perpendicular.
3 A line has slope ⁴⁄₅. What is the slope of a line perpendicular to it?
Perpendicular slopes are opposite reciprocals: flip ⁴⁄₅ to get ⁵⁄₄, then negate → −⁵⁄₄
4 A line has slope −²⁄₃. What is the slope of a line parallel to it?
Parallel lines have the exact same slope → −²⁄₃

Part D · Classifying Polygons on the Coordinate Plane

Use the figure ABCD to answer Questions 1–4.

D Using Slope & Distance to Classify

1 Using slope, what type of quadrilateral is ABCD?
✓ Every angle marked is 90°, so ABCD is a rectangle.
2 Find the length of side AB.
A(0,0) to B(4,0): d = √[(4−0)² + (0−0)²] = √16 → AB = 4
3 Find the length of side BC.
B(4,0) to C(4,3): d = √[(4−4)² + (3−0)²] = √9 → BC = 3
4 Find the length of the diagonal AC.
A(0,0) to C(4,3): d = √[(4−0)² + (3−0)²] = √[16+9] = √25 → AC = 5
5 Explain how the distance formula shows that ABCD is NOT a rhombus (a rhombus has 4 equal sides).
AB = 4 and BC = 3.
Since 4 ≠ 3, not all sides are equal, so ABCD is not a rhombus — it's a rectangle (only opposite sides equal, all right angles).
