Part A · Function Notation & Evaluating

Type the value only, e.g. 7.

A Evaluate the Function

1 If f(x) = 3x − 5, find f(4).
f(4) = 3(4) − 5 = 12 − 5 → f(4) = 7
2 If f(x) = x² − 3x, find f(−2).
f(−2) = (−2)² − 3(−2) = 4 + 6 → f(−2) = 10
3 A ride-share charges a $3 fee plus $2 per mile: C(x) = 2x + 3. Find C(6).
C(6) = 2(6) + 3 = 12 + 3 → C(6) = 15
Use the graph of f(x) = x + 1 below for Questions 4–5.
4 Using the graph, find f(3).
Read the graph at x = 3: the line passes through (3, 4) → f(3) = 4
5 Using the graph, find the value of x where f(x) = 0.
The line crosses the x-axis at (−1, 0) → x = −1

Part C · Slope & Linear Graphs

Type the value, or choose the matching equation.

C Rate of Change

1 Find the slope of the line shown through (1, 2) and (4, 11).
m = (11 − 2) / (4 − 1) = ⁹⁄₃ → m = 3
2 Find the slope of the line shown through (−2, 5) and (3, −5).
m = (−5 − 5) / (3 − (−2)) = −¹⁰⁄₅ → m = −2
3 Which equation represents the line graphed above?
✓ y-intercept (0,3) and slope −2 (falls 2 for every 1 right).
4 A table shows x: 0, 1, 2, 3 and y: 4, 7, 10, 13. Find the rate of change.
Rate of change = Δy/Δx = (7 − 4)/(1 − 0) = ³⁄₁ → rate = 3 (y increases 3 for every 1 increase in x)

Part D · Modeling & Comparing Functions

D Apply What You Know

MODELING The graph shows Maria's distance from home over 5 hours of driving at a constant rate. Write an equation for distance d in terms of time t, and find her speed.
Slope = rise/run = 150 ÷ 5 = 30.
d = 30t — her speed is 30 mph.
COMPARE Function A: f(x) = 3x + 2. Function B is given by the table x: 0, 1, 2 and y: 1, 5, 9. Which function has the greater rate of change?
Function A's rate of change is 3 (the coefficient of x).
Function B's rate of change is (5 − 1)/(1 − 0) = 4.
Function B has the greater rate of change (4 > 3).
IDENTIFY Which of these represents a direct variation (proportional) relationship: y = 4x or y = 4x + 2? Explain.
y = 4x is the direct variation. A proportional relationship must pass through the origin (0, 0) — plugging in x = 0 gives y = 0 only for y = 4x, not for y = 4x + 2 (which gives y = 2).
