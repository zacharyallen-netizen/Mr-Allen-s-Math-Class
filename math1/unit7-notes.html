1 Key Features of a Parabola

📖 New words
quadratic function
a function where the biggest power of x is 2 (it has an x²). Example: y = x² − 2x − 3.
parabola
the U-shaped graph of a quadratic function.
vertex
the turning point of the parabola. It is the lowest point or the highest point.
axis of symmetry
the vertical line through the vertex. It cuts the parabola into two mirror halves. We write it as x = (a number).
zeros
the x-values where the graph crosses the x-axis. There, y = 0. Zeros are also called roots or x-intercepts.
y-intercept
the point where the graph crosses the y-axis. There, x = 0.
maximum / minimum
the highest / lowest y-value on the graph. The vertex is one of these.
📌 Vertex = max or min. Axis of symmetry = vertical line through the vertex. x-intercepts = zeros. Opens up (a > 0, has a min) or down (a < 0, has a max).
y = (x − 1)² − 4 (same as y = x² − 2x − 3): vertex (1, −4), axis x = 1, zeros −1 & 3, y-int −3
a > 0 (y = x²): opens up, vertex is a minimum
a < 0 (y = −x²): opens down, vertex is a maximum
🧭 How to read the features from a graph
  1. Look at the arms. Up like a cup → opens up. Down like a hill → opens down.
  2. Find the turning point. That is the vertex. Write it as (x, y).
  3. Opens up → the vertex is a minimum. Opens down → it is a maximum.
  4. Draw a vertical line through the vertex. That is the axis of symmetry: x = (x-value of the vertex).
  5. Find where the graph crosses the x-axis. Those x-values are the zeros.
  6. Find where the graph crosses the y-axis. That is the y-intercept.

2 Graphing Quadratics

📖 New words
standard form
y = ax² + bx + c. The letters a, b and c stand for numbers, and a is not 0.
factored form
y = a(x − p)(x − q). The zeros are x = p and x = q.
midpoint
the number exactly halfway between two numbers. Add them and divide by 2.
📌 From factored form: plot the zeros, find the axis = midpoint of zeros, then the vertex, then a couple of symmetric points.
🧭 How to graph y = ax² + bx + c
  1. Factor. Set each factor equal to 0. Solve. These are the zeros.
  2. Find the axis: x = p + q2 (halfway between the zeros). If it does not factor, use x = −b2a.
  3. Put that x-value into the function. The answer is the y-value of the vertex.
  4. The y-intercept is c. Plot (0, c).
  5. Mirror (0, c) across the axis to get one more point.
  6. Connect the points with a smooth U shape.

Graph y = x² − 2x − 3

Box method: x² − 2x − 3 = (x − 3)(x + 1)
Step 1. Factor → zeros: (x − 3)(x + 1) → click to reveal x = 3, x = −1
Step 2. Axis = midpoint: 3 + (−1)2 = click to reveal x = 1
Step 3. Vertex (plug x = 1): 1² − 2(1) − 3 = click to reveal −4, so the vertex is (1, −4)
Step 4. y-intercept: c = −3 → click to reveal (0, −3)
✓ Step 5. Mirror point: (0, −3) is 1 left of the axis, so 1 right is click to reveal (2, −3). Connect all 5 points with a smooth U.
The finished graph: zeros, axis, vertex, y-intercept and mirror point

3 Vertex Form vs. Standard Form

📖 New words
vertex form
y = a(x − h)² + k. The vertex is the point (h, k).
h
the x-value of the vertex. Inside the parentheses it shows with the opposite sign: (x − 3) means h = 3, and (x + 3) means h = −3.
k
the y-value of the vertex. It is the number added at the end. Keep its sign.
expand
multiply out the parentheses and combine like terms.
📌 One parabola can be written three ways. They are all equal! Each form shows one feature fast.
Form & equationShows you fast
Standard
y = x² − 2x − 3		y-intercept (0, −3)
Factored
y = (x − 3)(x + 1)		zeros 3 and −1
Vertex
y = (x − 1)² − 4		vertex (1, −4)
Three forms of the same function
Same graph: the vertex comes from vertex form, the zeros from factored form, the y-intercept from standard form.
🧭 How to read vertex form y = a(x − h)² + k
  1. Find a: the number in front. a > 0 opens up. a < 0 opens down.
  2. Find h: look inside the parentheses and flip the sign. (x − 3) → h = 3. (x + 3) → h = −3.
  3. Find k: the number at the end. Keep its sign.
  4. Write the vertex as (h, k).
🧭 How to change vertex form into standard form
  1. Write (x − h)² as (x − h)(x − h). Multiply it out (use a box).
  2. Multiply every term by a.
  3. Add k to the number term.
  4. Check: put x = 0 into both forms. You should get the same y.

Worked example: y = 2(x − 1)² − 8

Decode the vertex form
Step 1. Vertex: click to reveal h = 1 and k = −8, so the vertex is (1, −8). a = 2 > 0, so it opens up.
Step 2. Square the binomial: click to reveal (x − 1)² = (x − 1)(x − 1) = x² − 2x + 1
Step 3. Multiply by a = 2: click to reveal 2x² − 4x + 2
Step 4. Add k = −8: click to reveal y = 2x² − 4x − 6
✓ Step 5. Check with x = 0: click to reveal Vertex form: 2(0 − 1)² − 8 = 2 − 8 = −6. Standard form: c = −6. ✓ Same!
y = 2(x − 1)² − 8 = 2x² − 4x − 6: vertex (1, −8), y-int (0, −6), zeros −1 and 3

4 Domain, Range & End Behavior

📖 New words
domain
all the x-values you are allowed to put in. For a quadratic, that is all real numbers.
range
all the y-values the graph reaches. It starts at the vertex.
end behavior
what the two arms do far to the left and far to the right (both up or both down).
interval notation
a short way to write a range. [−4, ∞) means −4 and everything bigger. A square bracket [ ] means “include this number.” ∞ always gets a round bracket ( ).
📌 Domain = all real numbers. Range = y ≥ min (opens up) or y ≤ max (opens down). End behavior: both ends up (a > 0) or both down (a < 0).
y = −x² + 4 opens down: max (0,4), range y ≤ 4, or (−∞, 4]
y = x² − 2x − 3 opens up: min −4, range y ≥ −4, or [−4, ∞). Both ends go up.
🧭 How to find the domain and range
  1. Domain: write all real numbers. (You can put in any x.)
  2. Find the vertex. Its y-value is k.
  3. Opens up → range is y ≥ k. Opens down → range is y ≤ k.
  4. Interval notation: opens up → [k, ∞). Opens down → (−∞, k].
  5. End behavior: a > 0 → both ends go up. a < 0 → both ends go down.

5 Creating Quadratic Equations

📖 New words
model
an equation that describes a real situation.
projectile
an object that is thrown or launched. It goes up, slows down, then falls back down.
h(t)
“h of t” = the height after t seconds. h(0) is the starting height.
📌 Area and projectile problems are quadratic. Set up, then factor or take roots.
🧭 How to solve an area problem
  1. Draw the rectangle. Label the width w. Label the length using w.
  2. Write: length × width = area.
  3. Multiply out. Move everything to one side so it equals 0.
  4. Factor and solve.
  5. A length cannot be negative. Keep only the positive answer.
MODEL A rectangle’s length is 2 more than its width and the area is 24. Find the width.
Label the sides with w
Let w = width → w(w + 2) = 24 → w² + 2w − 24 = 0 → (w + 6)(w − 4) = 0 → w = 4 (length 6). We throw out w = −6, because a width can’t be negative.
Check: 4 × 6 = 24 ✓
🧭 How to solve a projectile problem h(t) = at² + bt + c
  1. Starting height: h(0) = c.
  2. Lands: set h(t) = 0. Factor and solve. Keep the positive t.
  3. Time of the top: t = −b2a (or halfway between the zeros).
  4. Max height: put that t into h(t).

Worked example: a ball is thrown up. h(t) = −16t² + 32t + 48 (feet, seconds)

🧭 How to compare two functions
  1. Decide which feature the question asks about (max, min, zero, y-intercept).

7 Building Functions

📖 New words
(f + g)(x)
add the two functions: f(x) + g(x).
(f · g)(x)
multiply the two functions: f(x) · g(x).
distribute
multiply the outside term by EVERY term inside the parentheses.
📌 Build a new function by adding or multiplying functions. Multiplying two linear functions gives a quadratic.
🧭 How to build a new function
  1. Write each function inside parentheses.
  2. Adding? Combine like terms (x² with x², x with x, numbers with numbers).
  3. Multiplying? Distribute every term (use a box).
  4. Write the answer in standard form: ax² + bx + c.

l(x) = x + 3 and w(x) = x. Build the area A(x) = l·w.

x · x = x² and 3 · x = 3x, so A(x) = x² + 3x
