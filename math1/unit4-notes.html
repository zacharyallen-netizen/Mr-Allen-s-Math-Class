1 Sequences Are Functions

📖 Words to know
Sequence
— a list of numbers in order.
Term
— one number in the list.
Term number n
— the place of a term: 1st, 2nd, 3rd, …
an
— say "a sub n." It means the nth term. a1 is the first term. a4 is the fourth term.
Arithmetic
— you ADD the same number each time.
Geometric
— you MULTIPLY by the same number each time.
📌 A sequence is a function whose inputs are the term numbers 1, 2, 3, … Add → arithmetic → linear. Multiply → geometric → exponential.
TypePatternBecomes a…
Arithmetic2, 5, 8, 11 (+3 each)Linear function
Geometric2, 6, 18, 54 (×3 each)Exponential function
Each term number n goes to one term an. That makes it a function.
Graph (n, an): arithmetic dots make a line; geometric dots curve up.
Arithmetic: +3 each time
Geometric: ×3 each time

🪜 Steps: name the sequence

  2. All the differences the same? It is arithmetic. That number is d.
  3. Not the same? Divide each term by the one before it.
  4. All the ratios the same? It is geometric. That number is r.
  5. Neither one stays the same? It is neither.

2 Arithmetic Sequences

📖 Words to know
Common difference d
— the number you add each time. It can be negative.
Explicit formula
— finds ANY term right away from n.
Recursive formula
— finds the NEXT term from the one before it. an−1 means "the term before."
📌 Add the common difference d. Explicit: an = a1 + (n − 1)d. Recursive: an = an−1 + d.
3, 7, 11, 15: each bar is 4 taller than the one before

Sequence 3, 7, 11, 15, … Find a10.

d = 4, a1 = 3 → explicit: an = click to reveal 3 + (n − 1)·4 = 4n − 1
✓ a10 = 4(10) − 1 = click to reveal 39
From a1 to a10 is 9 jumps (10 − 1), not 10.

Translate forms: recursive a1 = 2, an = an−1 + 5 → explicit

a1 = 2, d = 5 → an = a1 + (n − 1)d: an = click to reveal 2 + (n − 1)·5
✓ Simplify: an = click to reveal 5n − 3
The terms are points on a line with slope d = 5

Now go the other way: explicit an = 3n + 1 → recursive.

a1 = ?  ·  an = an−1 + ?

🪜 Steps: arithmetic sequences
  1. Find a1, the first term.
  2. Find d. Subtract any term from the next one.
  3. Explicit: an = a1 + (n − 1)d.
  4. Put in the n you want. Do (n − 1) first. Then times d. Then add a1.
  5. Recursive: write a1 = first term and an = an−1 + d.

3 Geometric Sequences

📖 Words to know
Common ratio r
— the number you multiply by each time.
Exponent
— tells how many times to multiply. 34 = 3 · 3 · 3 · 3 = 81.
📌 Multiply by the common ratio r. Explicit: an = a1 · rn−1. Recursive: an = an−1 · r.
2, 6, 18, 54: each bar is 3 times as tall as the one before

Sequence 2, 6, 18, 54, … Find a5.

r = 3, a1 = 2 → explicit: an = click to reveal 2 · 3n−1
✓ a5 = 2 · 34 = 2 · 81 = click to reveal 162

Sequence 80, 40, 20, 10, … Find a6.

r = 40 ÷ 80 = click to reveal 12 (the terms shrink)
✓ a6 = 80 · (12)5 = 80 · 132 = click to reveal 2.5
🪜 Steps: geometric sequences
  1. Find a1, the first term.
  2. Find r. Divide any term by the one before it.
  3. Explicit: an = a1 · rn−1.
  4. Do the exponent first: (n − 1). Then the power rn−1. Then multiply by a1.
  5. Recursive: a1 = first term and an = an−1 · r.

4 Linear vs. Exponential

📖 Words to know
Linear function
— adds the same amount each step. Its graph is a straight line.
Exponential function
— multiplies by the same number each step: y = a · bx. Its graph curves.
📌 Constant difference → linear. Constant ratio → exponential. Exponential growth starts slow, then rockets up.
y = 2x + 1 (line) vs. y = 2x (curve) — the curve overtakes the line
Linear: +2 each step
Exponential: ×2 each step

x: 0, 1, 2, 3 and y: 3, 6, 12, 24. Linear or exponential? Write the function.

Differences 3, 6, 12. Ratios: click to reveal 2, 2, 2 → exponential, b = 2
✓ a = y when x = 0 = 3, so click to reveal y = 3 · 2x

x: 0, 1, 2, 3 and y: 5, 8, 11, 14. Linear or exponential? Write the function.

Differences: click to reveal 3, 3, 3 → linear, slope m = 3
✓ b = y when x = 0 = 5, so click to reveal y = 3x + 5
🪜 Steps: linear or exponential?
  1. Check that x goes up by 1 each time.
  2. Find the differences in y. All the same? Linear: y = mx + b.
  3. Not the same? Find the ratios in y. All the same? Exponential: y = a · bx.
  4. The start value (y when x = 0) is b for a line, and a for an exponential.

5 Growth & Decay

📖 Words to know
Initial value a
— the starting amount. It is y when x = 0.
Growth factor b
— the number you multiply by each time step.
Rate r
— the percent change, written as a decimal. 4% → 0.04.
Decay
— shrinking by the same percent each step.
Compound growth
— each step grows from the NEW amount, so the growth itself grows.
📌 y = a · bx. a = initial value. b = growth factor. b > 1 → growth; 0 < b < 1 → decay. Rate: growth b = 1 + r, decay b = 1 − r.
Heads up: In Topic 3, r was the common ratio. Here, r is the percent rate. The growth factor b plays the "ratio" job: b = 1 + r or b = 1 − r.
Growth: y = 1.5x
Decay: y = 10·(0.6)x
🎚 Try it: Move a and b. When is it growth? When is it decay? Watch the ×b arrows in the table.

A car worth $18,000 loses 10% of its value each year. Write the model. Find the value after 3 years.

a = 18,000, r = 0.10, decay → b = 1 − 0.10: click to reveal b = 0.9, so y = 18000(0.9)x
✓ x = 3: 18000(0.9)3 = 18000(0.729) = click to reveal $13,122
🪜 Steps: write a growth or decay model
  1. Find a, the starting amount.
  2. Change the percent to a decimal r. (4% → 0.04)
  3. Growth? b = 1 + r. Decay? b = 1 − r.
  4. Write y = a · bx.
  5. To find a value, put in x. Do the power first. Then multiply by a.

6 Key Features & End Behavior

📖 Words to know
Horizontal asymptote
— a flat line the graph gets closer and closer to, but never touches.
Domain
— all the x-values you can put in.
Range
— all the y-values that come out.
End behavior
— what the graph does far to the left and far to the right.
📌 Exponentials have a horizontal asymptote (usually y = 0), domain all real numbers, and range y > 0 (when a > 0). Exponential growth eventually exceeds any linear or quadratic.
y = 2x : y-intercept (0, 1), range y > 0, never touches the asymptote y = 0

🪜 Steps: key features of y = a · bx
  1. y-intercept: put in x = 0. Anything to the 0 power is 1, so you get a. The point is (0, a).
  2. Asymptote: y = 0.
  3. Domain: all real numbers.
  4. Range: y > 0 when a > 0.
  5. End behavior: b > 1 rises to the right. 0 < b < 1 falls toward 0 on the right.
