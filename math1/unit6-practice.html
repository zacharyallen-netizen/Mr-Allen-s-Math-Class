Part A · Multiplying Polynomials

Type the simplified expression, e.g. x²+5x+6 — you can type the exponent as ^2 or ².

A Multiply Binomials

1 Use the area model below to find the product (x + 3)(x + 2).
Add all 4 cells of the area model: x² + 3x + 2x + 6 → combine like terms → x² + 5x + 6
2 Multiply and simplify: (x − 4)(x + 4).
This is a difference of squares: (x)² − (4)² → x² − 16 (the middle terms −4x and +4x cancel)
3 Multiply and simplify: (2x + 1)(x − 3).
FOIL: (2x)(x) + (2x)(−3) + (1)(x) + (1)(−3) = 2x² − 6x + x − 3 → 2x² − 5x − 3
4 Multiply and simplify: (x + 5)².
(x+5)² = (x+5)(x+5) = x² + 5x + 5x + 25 → x² + 10x + 25
5 Subtract and simplify: (3x² − 2x + 5) − (x² + 4x − 1).
Flip every sign in the 2nd ( ): 3x² − 2x + 5 − x² − 4x + 1 → 2x² − 6x + 6
6 Multiply and simplify: (x − 2)(x − 5).
x² − 5x − 2x + 10 → x² − 7x + 10 (negative × negative = positive)

Part B · Factoring

Type the fully factored form, e.g. (x+3)(x+4).

B Factor Completely

1 Factor completely: x² + 7x + 12.
Find two numbers that multiply to 12 and add to 7 → 3 and 4 → (x + 3)(x + 4)
2 Factor completely: x² − 9.
Difference of squares: x² − 3² → (x + 3)(x − 3)
3 Factor completely: 2x² + 5x − 3.
Look for factors of 2 and −3 that combine to give 5x: try (2x − 1)(x + 3) → 2x² + 6x − x − 3 = 2x² + 5x − 3 ✓ → (2x − 1)(x + 3)
4 Factor completely by pulling out the GCF: 3x² + 12x.
GCF of 3x² and 12x is 3x → 3x(x + 4)
5 Factor completely: x² − 3x − 18.
3 · (−6) = −18 and 3 + (−6) = −3 → (x + 3)(x − 6)
6 Factor completely: x² + 10x + 25. (Hint: it is a perfect square.)
5 · 5 = 25 and 5 + 5 = 10 → (x + 5)(x + 5) = (x + 5)²

Part C · Solving Quadratic Equations

Type all solutions, e.g. x=2,3.

C Solve by Factoring or Square Roots

1 Solve by factoring: x² − 5x + 6 = 0.
Factor: (x − 2)(x − 3) = 0 → x − 2 = 0 or x − 3 = 0 → x = 2, 3
2 Solve using square roots: x² = 49.
Take the square root of both sides (don't forget ±): x = ±√49 → x = 7, −7
3 Solve by factoring: x² + 4x = 0.
Factor out x: x(x + 4) = 0 → x = 0 or x + 4 = 0 → x = 0, −4
4 Solve using square roots: 2x² − 8 = 0.
2x² = 8 → x² = 4 → x = ±√4 → x = 2, −2

Part E · Completing the Square

Find the missing corner tile, then solve.

E Missing Corner

1 What number c makes x² + 8x + c a perfect square?
Half of 8 is 4. 4² = 16. x² + 8x + 16 = (x + 4)².
2 Solve x² + 6x = 16 by completing the square.
Add 9: (x + 3)² = 25 → x + 3 = ±5 → x = 2 or x = −8

Part F · The Quadratic Formula

x = (−b ± √(b² − 4ac)) ÷ (2a). You may type answers like (4±sqrt(40))/4 or decimals.

F Formula Practice

x = −b ± √b² − 4ac2a
1 For x² + 3x − 10 = 0, find the discriminant b² − 4ac.
a = 1, b = 3, c = −10. 3² − 4(1)(−10) = 9 + 40 → 49
2 Solve x² + 3x − 10 = 0.
x = (−3 ± √49) ÷ 2 = (−3 ± 7) ÷ 2 → x = 2 or x = −5
3 Solve 2x² − 4x − 3 = 0. Round to the nearest hundredth, or type an exact answer.
(−4)² − 4(2)(−3) = 16 + 24 = 40. x = (4 ± √40) ÷ 4 → x ≈ 2.58 or x ≈ −0.58
