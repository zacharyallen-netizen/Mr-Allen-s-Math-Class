1 What is the common difference (d) of the sequence graphed above?
Each term increases by the same amount: 8−5=3, 11−8=3, 14−11=3 → d = 3
2 Which explicit formula matches the sequence?
✓ First term a1=5, common difference d=3, so aₙ = a1 + d(n−1).
3 Using a1 = 5 and d = 3, find a6.
a6 = 5 + 3(6−1) = 5 + 3(5) = 5 + 15 → a6 = 20

B Common Ratio & Explicit Formula

1 What is the common ratio (r) of the sequence graphed above?
Each term is multiplied by the same factor: 6÷3=2, 12÷6=2, 24÷12=2 → r = 2
2 Using a1 = 3 and r = 2, find a7.
a7 = 3(2)⁷⁻¹ = 3(2⁶) = 3(64) → a7 = 192
3 Which formula represents this geometric sequence?
✓ First term a1=3, common ratio r=2, so aₙ = a1·rⁿ⁻¹.
4 A geometric sequence has a1 = 100 and r = 0.5. Find a4.
a4 = 100(0.5)⁴⁻¹ = 100(0.5)³ = 100(0.125) → a4 = 12.5

Part C · Linear vs. Exponential Growth

Use the graph comparing f(x) = 3x + 1 and g(x) = 2ˣ.

C Compare the Functions

1 Which function has the greater value when x = 3?
✓ f(3)=3(3)+1=10 and g(3)=2³=8, so f(x) is greater at x=3.
2 Which function has the greater value when x = 5?
✓ f(5)=3(5)+1=16 and g(5)=2⁵=32, so g(x) has overtaken f(x).
3 For large enough x, which type of function will always eventually exceed the other?
Exponential growth multiplies each step, while linear growth only adds a fixed amount — over time, repeated multiplication always overtakes repeated addition → exponential

Part D · Growth & Decay Models

D Real-World Exponential Models

GROWTH A population of 200 bacteria doubles every hour. Write an exponential growth function P(t) and find the population after 5 hours.
Growth factor = 1 + 100% = 2 each hour.
P(t) = 200(2)ᵗ
P(5) = 200(2)⁵ = 200(32) = 6,400 bacteria.
DECAY A car worth $20,000 depreciates 15% per year. Write a decay function V(t) and estimate its value after 4 years.
Decay factor = 1 − 0.15 = 0.85 each year.
V(t) = 20000(0.85)ᵗ
V(4) = 20000(0.85)⁴ ≈ 20000(0.522) ≈ $10,440.
IDENTIFY A savings account earns 4% interest per year on a $500 deposit. Write the growth function A(t).
Growth factor = 1 + 0.04 = 1.04 each year.
A(t) = 500(1.04)ᵗ
