Part 1 · Warm-up for transformations

Reading Coordinates

Big idea

Every point has one address. Read x first, then y.

Words to know

Coordinate planeA grid made by two number lines that cross.
x-axisThe flat (horizontal) number line.
y-axisThe up-and-down (vertical) number line.
OriginThe point (0, 0), where the axes cross.
Ordered pairTwo numbers (x, y) that name a point. Order matters.
QuadrantOne of the 4 parts of the grid: I, II, III, IV.

A coordinate is an address on the grid. It is written as (x, y).

  • Always start at the origin, (0, 0). That is where the two axes cross.
  • x comes first. It tells you to go right (positive) or left (negative).
  • y comes second. It tells you to go up (positive) or down (negative).
Memory tip: You walk down the hall (x) before you take the elevator (y). Right or left first. Then up or down.

The axes split the grid into 4 quadrants. They are numbered I, II, III, IV, going counterclockwise from the top right.

Quadrantx is…y is…Example
I (top right)positivepositive(3, 2)
II (top left)negativepositive(−3, 2)
III (bottom left)negativenegative(−3, −2)
IV (bottom right)positivenegative(3, −2)
Try it

Tap any spot where grid lines cross. Watch how the coordinates are made.

Tap the grid to start.
Skills you need
  • Find the coordinates of a vertex on a shape.
  • Plot a point from its coordinates.
  • Tell the quadrant from the signs of x and y.
Common mistakes
  • Mistake: Reading y first, so (1, −2) becomes (−2, 1).Fix: Walk first (x: right or left), then ride the elevator (y: up or down).
  • Mistake: Going the wrong way for a negative.Fix: Negative x means left. Negative y means down.
  • Mistake: Counting the axis line as 1.Fix: Start counting at 0. Count the jumps, not the lines.
  • Mistake: Saying a point on an axis is in a quadrant.Fix: Points like (0, 4) or (−3, 0) sit on an axis. They are in no quadrant.
Part 2 · NC.8.G.3

Transformations on the Grid

Big idea

A rule tells you how every vertex moves. Move each vertex, then connect them.

Words to know

TransformationA move or change of a shape.
Pre-image / ImageThe shape before the move / the shape after.
Prime (A′)The mark for a moved point. Say “A prime.”
VertexA corner of a shape. Plural: vertices.
TranslationA slide. Every point moves the same way.
ReflectionA flip over a line, like a mirror.
RotationA turn around a point. Clockwise goes the way clock hands go.
DilationA stretch or shrink by a scale factor k.
CongruentSame size and same shape.
SimilarSame shape. The size can be different.

A transformation moves or changes a shape. The starting shape is the pre-image. The new shape is the image. We mark the image with a prime: point A becomes A′ (say “A prime”).

To move a shape, move each vertex (corner) with the rule. Then connect the new vertices.

TransformationRuleWhat happens
Translation (slide)(x + a, y + b)Add to x to go right. Add to y to go up. Subtract to go left or down.
Reflection over the x-axis(x, −y)Flip up and down. Change the sign of y.
Reflection over the y-axis(−x, y)Flip left and right. Change the sign of x.
Rotation 90° clockwise(y, −x)Switch x and y. Then change the sign of the new y.
Rotation 90° counterclockwise(−y, x)Switch x and y. Then change the sign of the new x.
Rotation 180°(−x, −y)Change both signs.
Dilation by scale factor k(kx, ky)Multiply both by k. k > 1 gets bigger. k < 1 gets smaller.

All rotations and dilations here are about the origin.

Same size or not? Slides, flips, and turns keep the same size and shape. The image is congruent. A dilation changes the size but keeps the shape. The image is similar.
Try it

Pick a transformation. Watch triangle ABC move. Compare the coordinates in the table.

a 3b −4
Skills you need
  • Write the coordinates of every vertex first.
  • Use the rule on each vertex to find the image.
  • Name the transformation by comparing before and after coordinates.
  • Decide if the image is congruent or similar.
Common mistakes
  • Mistake: Changing the sign of x for a flip over the x-axis.Fix: Over the x-axis, the y changes: (x, −y). The axis you flip over keeps its number.
  • Mistake: Mixing up clockwise and counterclockwise.Fix: Clockwise (y, −x). Counterclockwise (−y, x). Check: a shape in Quadrant I turns clockwise into Quadrant IV.
  • Mistake: Moving the wrong way in a translation.Fix: x + 4 is right 4. y − 3 is down 3.
  • Mistake: Adding for a dilation.Fix: A dilation multiplies: (kx, ky). Adding is a slide.
  • Mistake: Thinking a flipped or turned shape is not congruent.Fix: Slides, flips, and turns never change size. Only a dilation does.
Part 3 · NC.8.F.1

Is It a Function?

Big idea

A function gives each input exactly one output.

Words to know

InputThe x-value. What goes in.
OutputThe y-value. What comes out.
RelationAny set of input and output pairs.
FunctionA relation where each input has exactly one output.
Mapping diagramArrows that show which input goes to which output.
Vertical line testIf an up-and-down line hits a graph more than once, it is not a function.

A function is a rule where each input (x) has exactly one output (y).

The one test: Does any x-value go to two different y-values? If yes, it is not a function. Outputs can repeat. Inputs can’t go two places.
If you see a…Check this
TableLook at the x column. If an x repeats with a different y, it is not a function.
List of ordered pairsLook at the first numbers. Same as a table.
Mapping diagramEach input may have only one arrow leaving it.
GraphUse the vertical line test. If any up-and-down line hits the graph more than once, it is not a function.
Try it · Vertical line test

Slide the vertical line across the graph. Count how many times it hits.

Skills you need
  • Check a table or list of pairs for a repeated x.
  • Check that each input in a mapping has one arrow.
  • Use the vertical line test on a graph.
  • Explain why something is or is not a function.
Common mistakes
  • Mistake: Saying it is not a function because a y repeats.Fix: Outputs can repeat. Only check the inputs (x).
  • Mistake: Checking the y column instead of the x column.Fix: Look for the same x with two different y’s.
  • Mistake: Using a horizontal line on a graph.Fix: The test uses a vertical (up-and-down) line.
  • Mistake: Counting arrows that land on an output.Fix: Count the arrows that leave each input. One each is a function.
