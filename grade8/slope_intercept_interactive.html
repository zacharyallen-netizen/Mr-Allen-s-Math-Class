For y = ½x, what is y when x = 10?
y = ½ · 10 = 5.
For y = ½x, what is y when x = −8?
y = ½ · (−8) = −4.
Which line is steeper: y = x or y = ½x?
On y = x, y goes up 1 each time x goes up 1. On y = ½x, y only goes up ½. So y = x is steeper.
For y = ½x + 4, what is y when x = 2?
y = ½ · 2 + 4 = 1 + 4 = 5.
For y = ½x + 4, what is y when x = −6?
y = ½ · (−6) + 4 = −3 + 4 = 1.
A plant’s height after x weeks is y = ½x + 4 (in cm). How tall is it after 10 weeks? Type just the number.
y = ½ · 10 + 4 = 5 + 4 = 9. The plant is 9 cm tall.

Reflection Questions

On the line y = x, the x-value and the y-value are always…
y = x means y is the same number as x, so they are always equal. Example: (4, 4).
Which line goes DOWN from left to right?
The negative sign in front of x flips the line. So y = −x goes down as you move to the right.
Jordan says that on y = −x, when x = −3, y = −3. What is the correct y?
y = −(−3) = 3. Jordan forgot that the opposite of a negative number is positive.
Where does the line y = x + 3 cross the y-axis? Type the y-value.
On the y-axis, x = 0. So y = 0 + 3 = 3. The line crosses at (0, 3).
Which point is on the line y = x − 3?
5 − 3 = 2 ✓ so (5, 2) works. The others don't: 1 − 3 = −2, 0 − 3 = −3, 2 − 3 = −1.
Which equation matches this graph?
The line crosses the y-axis at −3, so the equation ends in − 3. It goes up 1 for every 1 step right, like y = x. So it is y = x − 3.
For y = ½x, what is y when x = 7? Type a decimal or a fraction.
y = ½ · 7 = 3.5 (or 7/2).
