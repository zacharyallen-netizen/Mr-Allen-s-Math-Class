Part 1 · NC.8.NS.1

Rational and irrational numbers

Big idea
  • A rational number can be written as a fraction of two integers. Its decimal stops (0.25) or repeats (0.3636…).
  • An irrational number's decimal never stops and never repeats.
  • The square root of a perfect square is rational: √49 = 7, √0.09 = 0.3, √900 = 30. Other square roots, like √50, are irrational.
  • π is irrational, but watch for tricks: 5π ÷ π = 5, which is rational.

Watch me · classify each number

√64, √65, 0.121212…, 4π ÷ π

Show the steps
  1. √64 = 8 because 8 × 8 = 64. Rational.
  2. 65 is not a perfect square (8² = 64 and 9² = 81), so √65 never ends or repeats. Irrational.
  3. 0.121212… repeats "12" forever. Rational.
  4. 4π ÷ π: the π's divide out, leaving 4. Rational.

Watch me · decimal expansions

Describe the decimal for 3/8, 4/11 and √5.

Show the steps
  1. 3/8: divide 3 by 8 to get 0.375. It stops: terminating.
  2. 4/11: divide 4 by 11 to get 0.363636…. It repeats: repeating.
  3. √5 is not a perfect square: nonterminating and nonrepeating (irrational).

Part 2 · NC.8.EE.1

Exponent rules

Big idea: the base stays the same. Only the exponents change.
  • Multiplying, same base: add the exponents. 3² · 3⁵ = 3⁷ (not 9⁷).
  • Dividing, same base: subtract. 5⁹ ÷ 5³ = 5⁶.
  • Power of a power: multiply. (5⁴)² = 5⁸.
  • Negative exponent: flip to a fraction. 2⁻⁴ = 1/2⁴ = 1/16. A negative exponent does not make the number negative.

Watch me

Find the value of (5⁻²)(5⁻¹).

Show the steps
  1. Same base, multiplying, so add the exponents: −2 + (−1) = −3. That gives 5⁻³.
  2. Negative exponent means flip: 5⁻³ = 1/5³.
  3. 5³ = 5 · 5 · 5 = 125, so the answer is 1/125.

Watch me

Simplify 2³ · 2⁴ · 2².

Show the steps
  1. All the bases are 2, so the answer has base 2. Do not multiply the 2's together.
  2. Add the exponents: 3 + 4 + 2 = 9. The answer is 2⁹.

Part 3 · NC.8.EE.7

Solving equations and counting solutions

Big idea: simplify each side first (distribute, combine like terms), then compare.
  • Different numbers of x on each side → exactly one solution. Solve it.
  • Same x-terms, different numbers → no solution. Example: 2x + 5 = 2x + 1.
  • Both sides exactly the same → infinitely many solutions. Example: 3(x + 2) = 3x + 6.

Watch me · solve

Solve 3(x + 4) = 2(x + 5).

Show the steps
  1. Distribute: 3x + 12 = 2x + 10.
  2. Subtract 2x from both sides: x + 12 = 10.
  3. Subtract 12 from both sides: x = −2.
  4. Check: 3(−2 + 4) = 6 and 2(−2 + 5) = 6 ✓

Watch me · the answer is a fraction

Solve 2x + 7 = −4x + 10.

Show the steps
  1. Add 4x to both sides: 6x + 7 = 10.
  2. Subtract 7: 6x = 3.
  3. Divide by 6: x = 3/6 = 1/2 (or 0.5). Fraction answers are fine.

Watch me · find the missing number

For what value of h does x + 2 = (3x + h)/3 have infinitely many solutions?

Show the steps
  1. Clear the fraction: multiply both sides by 3. That gives 3x + 6 = 3x + h.
  2. For infinitely many solutions, both sides must match exactly. The x-terms already match (3x).
  3. So the numbers must match too: h = 6.

Part 4 · NC.8.F.1

Is it a function?

Big idea: a function gives each input exactly one output.
  • Look for an input (x) that repeats. If it repeats with different outputs, it is not a function.
  • Outputs (y) can repeat. A table where every y is 4 is a function.
  • In a mapping diagram, each input can have only one arrow leaving it. Two inputs can point to the same output.
  • A pattern or rate of change has nothing to do with it. Only check the inputs.

Watch me

Is {(3, 1), (5, 2), (3, 7), (8, 1)} a function?

Show the steps
  1. List the inputs: 3, 5, 3, 8. The input 3 shows up twice.
  2. Its outputs are 1 and 7, which are different.
  3. So the input 3 has two outputs: not a function.
  4. The two 1's in the outputs (for 3 and 8) are fine. They do not break the rule.

Part 5 · NC.8.G.3

Transformations on the coordinate plane

Big idea: each move has a coordinate rule.
  • Translate a left/right, b up/down: (x + a, y + b). Left and down are subtracting.
  • Reflect across the x-axis: (x, −y). Across the y-axis: (−x, y).
  • Rotate about the origin: 90° clockwise (y, −x) · 90° counterclockwise (−y, x) · 180° (−x, −y).
  • Dilate by scale factor k about the origin: (kx, ky). Lengths multiply by k. Area multiplies by k².
  • For a sequence of moves, do them in order, one step at a time.

Watch me · two moves

Point M(2, 5) is reflected across the y-axis, then translated 3 units right and 4 units down. Where does it end up?

Show the steps
  1. Reflect across the y-axis, (x, y) → (−x, y): M(2, 5) → (−2, 5).
  2. Translate 3 right, 4 down, (x + 3, y − 4): (−2, 5) → (1, 1).

Watch me · dilation and area

A 6-by-4 rectangle is dilated by a scale factor of 1/2. What is the area of the image?

Show the steps
  1. Multiply each side length by 1/2: 6 → 3 and 4 → 2.
  2. New area: 3 × 2 = 6 square units.
  3. Check: the old area was 24, and 24 × (1/2)² = 24 × 1/4 = 6 ✓. The area does not just get cut in half.
