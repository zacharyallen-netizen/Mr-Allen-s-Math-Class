What is Slope?

Imagine you're walking up a hill. Some hills are steep, some are gentle. Slope is the mathematical way to measure that steepness.

Slope measures the rate of change — how much the y-value changes for every 1 unit change in x. It tells us two things:
1. How steep the line is
2. Which direction it goes (up or down, left to right)

We use the letter m to represent slope. In the equation y = mx + b:

m = the slope (steepness and direction)
b = the y-intercept (where the line crosses the y-axis)
📝 Write this in your notes: "Slope = rate of change = rise over run = m"
In y = mx + b, what does the letter m stand for?
In y = mx + b, m is the slope. (b is the y-intercept.)
What is the slope of y = 4x + 7? Type just the number.
Match it to y = mx + b. The number in front of x is m, so m = 4. (7 is b, the y-intercept.)
This hill goes right 4 and up 3. If you walk right 8 on the same hill, how far up do you climb?
Right 8 is 2 groups of right 4. Each group climbs 3. So you climb 3 + 3 = 6. The slope stays the same: 3/4 = 6/8.

Finding Slope from a Graph: Rise Over Run

To find slope from a graph, pick any two points on the line, then count:

Slope = rise (vertical change)run (horizontal change)

Rise = how far you move up or down (count vertical grid squares)
Run = how far you move left or right (count horizontal grid squares)

Example 1: Count the slope

Here's a line passing through (1, 2) and (4, 5).

The line with two points marked. Click Next to see the rise and run.

Example 1: Counting Rise and Run

Starting at (1, 2):

→ Count UP 3 squares (rise = 3)
→ Count RIGHT 3 squares to reach (4, 5) (run = 3)

Slope = riserun = 33 = 1

Example 2: A steeper line

Line through (1, 1) and (3, 5).

→ Rise = 4 (count up from 1 to 5)
→ Run = 2 (count right from 1 to 3)

Slope = 42 = 2

Example 3: Negative slope (going downhill)

Line through (1, 6) and (4, 3).

→ Rise = −3 (count DOWN from 6 to 3 — negative because you go down!)
→ Run = 3 (count right from 1 to 4)

Slope = −33 = −1
📝 If you count down, the rise is negative. That's what makes the slope negative!
Count the rise and the run from one dot to the other. What is the slope?
Rise: up 4 (from y = 2 to y = 6). Run: right 2 (from x = 1 to x = 3). Slope = 4/2 = 2.
Find the slope of this line. Use the two dots.
From (0, 6), count down 4 to y = 2: rise = −4. Then right 2: run = 2. Slope = −4/2 = −2.
Find the slope of this line. Write it as a fraction in simplest form, like 3/4.
Rise: up 4 (from −1 to 3). Run: right 6 (from −2 to 4). Slope = 4/6. Divide top and bottom by 2: 2/3.

The Slope Formula

When you have two points but no graph, use the slope formula:

m = y2 − y1x2 − x1
(x1, y1) is the first point
(x2, y2) is the second point
The numerator (top) is the rise. The denominator (bottom) is the run.

Example 1: Find the slope of the line through (2, 3) and (5, 9)

Step 1: Label your points

(x1, y1) = (2, 3)
(x2, y2) = (5, 9)

Example 1 (continued)

Step 2: Substitute into the formula

m = 9 − 35 − 2

Step 3: Simplify

m = 63 = 2

rise ÷ run = 6 ÷ 3 = 2

📝 The slope is 2, which means for every 1 unit you move right, you move up 2 units.

Example 2: (−1, 4) and (3, −2)

Step 1: Label your points

(x1, y1) = (−1, 4)
(x2, y2) = (3, −2)

Step 2: Substitute

m = −2 − 43 − (−1)

Example 2 (continued)

Step 3: Simplify carefully — watch the signs!

m = −64 = −32
Important: Always simplify your fraction! −⁶⁄₄ reduces to −³⁄₂.
The negative sign means the line goes downhill (left to right).

Going DOWN 6 while going right 4: m = −6 ÷ 4 = −3/2

⚠️ Common mistake: 3 − (−1) = 3 + 1 = 4, NOT 3 − 1 = 2. Subtracting a negative = adding!

Example 3: (2, 5) and (6, 5)

m = 5 − 56 − 2 = 04 = 0
Zero in the numerator → slope = 0 → horizontal line!
Both y-values are the same, so there's no vertical change.

Flat line: rise = 0, so m = 0

Example 4: (3, 1) and (3, 7)

m = 7 − 13 − 3 = 60 = undefined
Zero in the denominator → slope is undefined → vertical line!
Both x-values are the same. Division by zero is undefined.

Vertical line: run = 0, and we cannot divide by 0

Use the slope formula to find the slope through (1, 2) and (3, 8).
m = (8 − 2) / (3 − 1) = 6 / 2 = 3.
Find the slope through (−4, 1) and (2, −2). Write a fraction in simplest form.
m = (−2 − 1) / (2 − (−4)) = −3 / 6. Simplify: −1/2.
A line goes through (2, 3) and (6, y). Its slope is 2. What is y?

(6, y) is somewhere on the dashed line x = 6.

Run: 6 − 2 = 4. Slope 2 means rise ÷ 4 = 2, so the rise is 8. y = 3 + 8 = 11. Check: (11 − 3) / (6 − 2) = 8/4 = 2 ✓

Comprehensive Practice

Mixed practice from every section: what slope means, the four types, rise over run, and the slope formula. If an answer is a fraction, type it like 3/4 or -1/2.

What does slope measure?
Slope measures how steep a line is (and which way it goes). Where the line crosses the y-axis is b, the y-intercept.
Find the slope through (1, 3) and (4, 9).
m = (9 − 3) / (4 − 1) = 6 / 3 = 2.
Jay says, “A vertical line has a slope of 0.” Is Jay right?

A vertical line

No. A vertical line has run = 0, and we can't divide by 0. So its slope is undefined. A horizontal (flat) line is the one with slope 0.
Find the slope through (2, 8) and (5, 2).
m = (2 − 8) / (5 − 2) = −6 / 3 = −2.
What is the slope of this line? Write a fraction, like 1/2.
Rise: up 3 (from −2 to 1). Run: right 4 (from 0 to 4). Slope = 3/4.
Find the slope through (−2, −1) and (4, 2). If the answer is a fraction, type it as a/b (like 3/4).
m = (2 − (−1)) / (4 − (−2)) = 3 / 6. Simplify: 1/2.
Find the slope through (−3, 5) and (1, −3).
m = (−3 − 5) / (1 − (−3)) = −8 / 4 = −2.
Find the slope through (4, 7) and (4, −2). Type “undefined” if the slope is undefined.
m = (−2 − 7) / (4 − 4) = −9 / 0. We can't divide by 0, so the slope is undefined (a vertical line).
Find the slope through (−5, 3) and (7, 3).
m = (3 − 3) / (7 − (−5)) = 0 / 12 = 0 (a horizontal line).
A ramp rises 2 feet over a run of 10 feet. What is its slope? Write a fraction in simplest form.
slope = rise / run = 2 / 10. Divide top and bottom by 2: 1/5.
A line goes through (1, 4) and (x, 10). Its slope is 3. What is x?

(x, 10) is somewhere on the dashed line y = 10.

Rise: 10 − 4 = 6. Slope 3 means 6 ÷ run = 3, so the run is 2. x = 1 + 2 = 3. Check: (10 − 4) / (3 − 1) = 6/2 = 3 ✓
