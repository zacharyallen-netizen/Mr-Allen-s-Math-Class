Modeling the Rules — See WHY

Each rule comes from writing out the repeated multiplication. Click each card to reveal the reasoning.

Product Rule · x³ × x² = x⁵
x·x·x × x·x = x·x·x·x·x = x⁵. Count the factors: 3 + 2 = 5. Same base → ADD the exponents.
Quotient Rule · x⁵ ÷ x² = x³
x·x·x·x·x ÷ x·x → cancel 2 matching pairs → x·x·x = x³. Cancel matching factors: 5 − 2 = 3. Same base → SUBTRACT the exponents.
Power Rule · (x²)³ = x⁶
Three copies of x²: (x·x)(x·x)(x·x) = x⁶. 2 × 3 = 6. Power to a power → MULTIPLY.
Zero Exponent · x⁰ = 1
x·x·x ÷ x·x·x = 1 (anything divided by itself is 1) — but by the quotient rule this also equals x³⁻³ = x⁰. So x⁰ = 1.
Negative Exponent · x⁻³ = 1/x³
x·x ÷ x·x·x·x·x = x²⁻⁵ = x⁻³ — but cancelling factors leaves 1/x³. So a negative exponent means "flip it": x⁻ⁿ = 1/xⁿ.

ERROR ANALYSIS Simplify (3x²)³. A student wrote 3x⁶. What went wrong?
The coefficient 3 must ALSO be cubed: 3³ = 27. Correct: 27x⁶. The power rule applies to EVERYTHING inside the parentheses.
