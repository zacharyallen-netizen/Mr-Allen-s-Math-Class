Solar Payback Challenge

Six rounds, 60 seconds each. Find the month when solar pays for itself, or set the install cost to hit a target month. Faster answers earn bonus points.

NC.8.EE.8 · NC.8.F.2 · Science ESS.8.4.4

The payback rule

Solar: S = install + (solar bill)m. Grid: G = (grid bill)m. Set them equal and solve:

install = (grid bill − solar bill) × m  →  m = install ÷ (grid bill − solar bill)

All costs are made up for practice.
