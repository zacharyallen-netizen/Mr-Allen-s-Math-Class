Strategies

Math Test-Taking Strategies

Review every time
1Box the question.
Before any math, draw a box around what they are actually asking for. Is it x? The image of point B? The number of solutions?
2Hunt for trap words.
Circle NOT, EXCEPT, greatest, least, all. One missed "NOT" flips the whole answer.
3Plug it back in.
Got x = 5? Put 5 into the ORIGINAL equation. Both sides match → you're right. Works on Multiple Choice too: test each choice.
4Eliminate first.
Cross out choices that can't be right (wrong sign, wrong quadrant, too big). Two left is a 50/50 — much better than 25%.
5Select All = True/False.
Judge every option on its own: T or F. Don't stop after one. Expect 2 or more correct.
6Numeric Entry has no safety net.
No choices to compare, so check it twice. Watch negative signs, simplify fractions, and give the form asked for (fraction vs. decimal).
7Draw it.
Sketch a quick grid, mapping diagram, or number line on scratch paper. Seeing it beats picturing it — especially for G.3 and F.1.
8Estimate, then check.
Make a quick guess before solving. If your final answer is way off from your estimate, go back and look.
9Wrong answers are built from mistakes.
Test writers put common errors in the choices (added exponents instead of multiplying, rotated the wrong way). If your answer is there, still double-check it.
10Never leave one blank.
There is no penalty for guessing. Eliminate what you can, then make your best pick and move on.

NS.1

Rational & Irrational Numbers

Quick Refresher
I can tell rational from irrational numbers and write a repeating decimal as a fraction.

Rational

Can be written as a fraction ab of integers (b ≠ 0).
Its decimal ends or repeats.
−7   38   0.25   0.3   √49 = 7   √0.25 = 0.5

Irrational

CANNOT be written as a fraction.
Its decimal never ends AND never repeats.
π   √2   √20   0.1010010001…
√ of a whole number that is NOT a perfect square → irrational.

Where numbers live

Every real number is either rational or irrational — never both. Integers, whole numbers, and natural numbers are all inside the rational box.
√49 = 7, so it's a natural number — even with a square root sign!

Repeating decimal → fraction: the 9's Rule

  1. Count the repeating digits.
  2. Denominator = that many 9's (one 9 for each repeating digit).
  3. Numerator = the repeating digits.
  4. Simplify.
0.27 = 0.272727…
2 digits repeat → 99
2799 = 311  (÷ 9)
Repeating digitsDenominatorExample
1 digit90.3 = 39 = 13
2 digits990.45 = 4599 = 511
3 digits9990.125 = 125999
Remember: the 9's rule works when the decimal starts repeating right after the decimal point. Always simplify your fraction.

Integer Exponents

Quick Refresher
I can use the properties of integer exponents to write equivalent expressions.
RuleIn wordsExample
Product  am · an = am+nSame base, multiplying → add exponents23 · 25 = 28
Quotient  am ÷ an = am−nSame base, dividing → subtract (top − bottom)57 ÷ 59 = 5−2
Power of a power  (am)n = amnExponent outside parentheses → multiply(x4)3 = x12
Power of a product  (ab)n = anbnGive the exponent to every factor inside(2y3)2 = 4y6
Zero  a0 = 1Anything (not 0) to the zero power is 1(−8)0 = 1
Negative  a−n = 1anNegative exponent → flip it across the fraction bar. It does NOT make the number negative.4−2 = 116

Why do we ADD exponents?

An exponent counts how many times the base is multiplied. Put the groups together and count.
Careful: (−4)2 = 16 but −42 = −16. The negative is only inside the power if it's inside the parentheses. Final answers usually have positive exponents only.
EE.7

Solving Linear Equations & Inequalities

Quick Refresher
I can solve multi-step equations and inequalities (variables on both sides) and decide how many solutions an equation has.

The 4-step game plan

  1. Distribute to clear parentheses.
  2. Combine like terms on each side.
  3. Collect variables on one side (inverse operations).
  4. Isolate the variable. Then check.
Fractions? Multiply EVERY term by the LCD to clear them first.
3(x − 4) + 5 = x + 9
3x − 12 + 5 = x + 9
3x − 7 = x + 9
2x − 7 = 9
2x = 16 → x = 8
Check: 3(4)+5 = 17  and  8+9 = 17 ✓

How many solutions? — look at what's left when the variables cancel

One solutionNo solutionInfinitely many solutions
You end with x = a number.Variables cancel, you get a false statement.Variables cancel, you get a true statement.
4x + 1 = 2x + 7
x = 3		2(x + 3) = 2x + 5
6 = 5 ✗		3(x + 2) = 3x + 6
6 = 6 ✓
Different slopes (x-coefficients)Same x-coefficients, different constantsBoth sides are exactly the same

Inequalities: same steps + ONE rule

Multiply or divide both sides by a negative → flip the sign.
−3x + 7 > 19
−3x > 12
x < −4  (÷ −3 → flip)
Open circle: −4 is NOT included (<). Closed circle for ≤ or ≥.

Word problems → read the context

"At most" → ≤    "at least" → ≥
If the answer must be a whole number (people, tickets, shirts), round to what makes sense — usually down for "can afford."
F.1

What Is a Function?

Full Notes — New
I can explain that a function gives each input exactly one output, and decide if a table, graph, mapping diagram, or list of ordered pairs is a function.

Definition

A function is a rule that assigns to each input (x) exactly one output (y). The graph of a function is the set of ordered pairs (input, output).
Think of a vending machine: press B4 → you always get the same snack. If B4 sometimes gave chips and sometimes gave cookies, the machine would be broken — not a function.

Vocabulary

RelationAny set of ordered pairs.
Input / DomainThe x-values (what goes in).
Output / RangeThe y-values (what comes out).
FunctionA relation where no input has two different outputs.

The ONE question to ask

"Does any x repeat with a different y?"
  • Yes → NOT a function.
  • No → function.
  • Repeated y-values are fine! Two kids can share a birthday.

Four ways to see it

1. Table

2. Ordered pairs

3. Mapping diagram

Count arrows leaving each input: more than one arrow from the same input → NOT a function.

4. Graph — Vertical Line Test

Function ✓ — hits once
NOT ✗ — hits twice
Slide a vertical line across. If it ever touches the graph in 2+ points → NOT a function.

Functions in real life

  • Function: input = number of $8 tickets, output = total cost. Each number of tickets has one cost.
  • Function: input = a student, output = their birthday.
  • NOT: input = an age, output = a student with that age. Age 13 could match many students.
Benchmark trick: "Which value of k makes the relation NOT a function?" Look for the choice that matches an x-value already used with a different y. A vertical line (x = 2) is never a function; a horizontal line (y = 2) always is.
G.3

Transformations with Coordinates

Full Notes — New
I can describe the effect of translations, reflections (over the x- or y-axis), rotations (90°, 180°, 270° about the origin), and dilations (about the origin) using coordinates.

Vocabulary

Pre-imageThe original figure: A, B, C
ImageThe new figure, named with primes: A′, B′, C′
Rigid motionMoves a figure but keeps its size & shape → congruent (≅)
DilationStretches or shrinks → similar (~), not congruent
Scale factor (k)k > 1 enlarges; 0 < k < 1 shrinks

Example: reflect △ABC over the y-axis

A(1, 1) → A′(−1, 1)   B(4, 1) → B′(−4, 1)   C(1, 3) → C′(−1, 3)
x changes sign, y stays the same.
