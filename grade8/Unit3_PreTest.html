Solving Linear Equations

Standard assessed: NC.8.EE.7

Name: Date: Period:
SCORE3.0Basic Understanding

NC.8.EE.7 Solve linear equations in one variable.

• I can solve one-step and two-step equations using inverse operations.

Match each vocabulary term to its definition, then solve each equation.

coefficient A. Terms with the same variable raised to the same power.
constant B. The value of the variable that makes the equation true.
inverse operations C. A number multiplied by a variable.
solution D. Operations that undo each other, such as + and −.
distributive property E. A term with no variable — just a number.
like terms F. Multiplying a factor across each term inside parentheses.

Keep the equation balanced — worked example

2x + 5 = 13 → subtract 5 → 2x = 8 → divide by 2 → x = 4

Whatever you do to one side, do to the other.
