Part 1 · NC.8.F.1 · Notes 6.1

Functions

Remember

A function gives each input exactly one output.

  • The input is x. The output is y.
  • Outputs may repeat. Only an input with two different outputs breaks the rule.
  • Mapping diagram: count the arrows leaving each input. Graph: use the vertical line test.
Part 2 · NC.8.F.4 · Notes 6.2

Slope

Remember

Slope = rate of change = rise over run = m.

  • From a graph: count the rise (up or down), then the run (right). Down is a negative rise.
  • Slope formula: m = (y₂ − y₁) ÷ (x₂ − x₁). Subtracting a negative means add.
  • Four types: positive ↗, negative ↘, zero (flat) →, undefined (vertical) ↕.
Part 3 · NC.8.F.3 · Slope-intercept notes

Slope-Intercept Form

Remember

y = mx + b

  • m is the slope: the number in front of x.
  • b is the y-intercept: where the line crosses the y-axis (when x = 0).
  • To test a point, plug in x and see if you get y.
Part 4 · NC.8.F.3 · NC.8.F.4 · Notes 6.3

Tables → Equations

Remember
  • Slope from a table: change in y ÷ change in x (Δy ÷ Δx).
  • b is y when x = 0. No x = 0 row? Work backward up the table to x = 0.
  • A table is linear when Δy ÷ Δx is the same every time. Always divide. Don’t just eyeball Δy.
Part 5 · NC.8.F.4 · Notes 6.4

Linear Functions in Real-World Context

Remember
  • m = rate of change. Key words: per, each, every.
  • b = starting value (when x = 0). Key words: flat fee, sign-up fee, starting amount.
  • Going up over time (filling, earning): m is positive. Going down (draining, using up): m is negative.
Part 6 · NC.8.F.2 · Notes 6.5

Comparing Functions

Remember
  • Find m and b for both functions first.
  • Rate of change: compare the slopes (m). Starting value: compare the y-intercepts (b).
  • When do they cost the same? Set the two equations equal.
Part 7 · NC.8.F.5 · Notes 6.6

Graphs That Tell a Story

Remember
  • Read left to right. Up = increasing. Down = decreasing. Flat = staying the same.
  • Steeper = faster change. Gentler = slower change.
  • Distance from home goes down when someone goes back home.
Part 8 · NC.8.EE.8 · Notes 6.7

Systems of Equations

Remember
  • The solution is the point where the lines cross. It makes both equations true.
  • Different slopes: one solution. Same slope, different b: parallel, no solution. Same line: infinitely many.
  • Substitution: put the “y =” expression in place of y in the other equation. Solve for x, then find y.
