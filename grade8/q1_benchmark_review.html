The Real Number System

NC.8.NS.1 · NC.8.NS.2
REMEMBER A rational number can be written as a fraction of two integers. Its decimal ends or repeats. Square roots of perfect squares are rational. An irrational number's decimal never ends and never repeats, like √2 and π. Rational + irrational is irrational. A rational number (not 0) × an irrational number is irrational.

Part 2

Exponent Rules with Monomials

NC.8.EE.1
REMEMBER Numbers go with numbers. Letters go with letters. Multiply → ADD the exponents. Divide → SUBTRACT the exponents. Power to a power → MULTIPLY the exponents, and raise the number to the power too.

How to type an exponent: use ^. For example, type 12m^10 for 12m10. Type - for a negative.
