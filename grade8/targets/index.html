How to use the targets

  1. Find the standard we are working on (or click Try it in your I Can Tracker).
  2. Work the problem on paper first, then pick an answer.
  3. If it's wrong, read the note — it tells you what mistake that answer comes from — and try again. Use Hint if you're stuck.
  4. When you get it, read How to solve it, then set that statement to Got it ✓ in your tracker.
