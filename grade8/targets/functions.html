What a function is

Approaching · score 3

F.1-1Approaching (3)✓ Solved

I can define a function as a relationship where each input maps to exactly one output.

Mr. Allen pairs each student in his class (input) with the month the student was born (output). Which statement is correct?
Hint: Ask: can one student have two different birth months?
How to solve it
  1. A function gives each input exactly one output.
  2. Input = a student. Output = that student's birth month.
  3. Each student has only one birth month. Sharing a month is fine.
  4. So the relation is a function.

Hint: Look for any input (x-value) that is paired with two different outputs.

  5. Mapping 1 → 5, 2 → 5, 3 → 8: each input has one arrow — a function.

Hint: Picture sliding a straight up-and-down line across each graph. Does it ever hit the graph twice?
How to solve it

  4. The U opening up is hit only once by every vertical line, so it is the function.

F.3-4Approaching (3)✓ Solved

Use rise over run to find the slope of the line. Then give the y-intercept.
Hint: Count how far up and how far right you move from (0, −3) to (2, 5).
How to solve it
  1. From (0, −3) to (2, 5): rise = 5 − (−3) = 8 (up).
  2. Run = 2 − 0 = 2 (right).
  3. Slope = rise ÷ run = 8 ÷ 2 = 4.
  4. The line crosses the y-axis at (0, −3), so the y-intercept is −3.

The graph shows a hiker’s elevation over time. Which description of the intervals is correct?
Hint: Name each piece by its start and end times on the x-axis. Is the piece going up, flat, or going down?
How to solve it
  1. 0 to 2 h: 500 → 1,500 ft, going up → increasing.
  2. 2 to 3 h: stays at 1,500 ft → constant.
  3. 3 to 5 h: 1,500 → 2,300 ft → increasing.
  4. 5 to 8 h: 2,300 → 500 ft → decreasing.

I can explain whether a section of a graph is linear or non-linear by referring to its rate of change.

The table shows a hot-air balloon’s height. Which explanation about the section from 3 to 6 minutes is correct?
Hint: Find how much the height changes each minute from 3 to 6. Are the changes all the same?
How to solve it
  1. 0 to 3 min: +20, +20, +20. Same rate → linear.
  2. 3 to 6 min: 60 → 70 is +10, 70 → 90 is +20, 90 → 120 is +30.
  3. The rate changes, so the section from 3 to 6 min is non-linear (it curves and gets steeper).

F.5-7Proficient (4)✓ Solved

I can sketch a graph with several features (for example, speeding up, constant, then slowing down) from a verbal description.

A subway train leaves a station. It speeds up for 30 seconds, travels at a constant speed for 2 minutes, then slows down to a stop in 20 seconds. It waits at the next station for 40 seconds. Which graph shows the train’s speed?
Hint: Speed goes up, stays the same, goes down to 0, then stays at 0. Check the times too.
How to solve it
  1. 0–30 s: speeding up, so the graph rises from 0.
  2. 30–150 s (2 minutes): constant speed, so the graph is flat.
  3. 150–170 s: slowing to a stop, so it falls to 0. 20 s is shorter than 30 s, so it is steeper than the rise.
  4. 170–210 s: waiting, so it stays flat at speed 0.

I can analyze a graph and explain what its features mean in the context of the real-world situation.

The graph shows the gallons of gas in a car’s tank over time. Which explanation of the graph is correct?
Hint: The y-axis is gallons of gas. What makes gas go down, stay the same, or go up?
How to solve it
  1. 0–2 h: 14 → 8 gal, using (14 − 8) ÷ 2 = 3 gal per hour. The car is driving.
  2. 2–2.5 h: flat at 8 gal. The car is parked.
  3. 2.5–3 h: 8 → 14 gal quickly. The driver fills the tank.
  4. 3–5 h: 14 → 10 gal, using (14 − 10) ÷ 2 = 2 gal per hour. Less steep means gas is used more slowly.

F.5-9Mastery (5)✓ Solved

I can sketch and justify a non-linear graph and explain why the rate of change is not constant.

A class drops a ball from a 100-meter tower and records its height each second. Which explanation of the graph of height vs. time is correct?
Hint: Find how much height the ball loses each second. Are those amounts the same?
How to solve it
  1. Drops each second: 100 → 95 (5 m), 95 → 80 (15 m), 80 → 55 (25 m), 55 → 20 (35 m).
  2. The changes are not the same, so the rate of change is not constant.
  3. The graph starts at (0, 100) and curves down, getting steeper as the ball speeds up.
