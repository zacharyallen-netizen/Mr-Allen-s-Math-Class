Lines m and n are parallel. Transversal t crosses them.
What kind of angle pair are ∠4 and ∠6, and how are their measures related?
Hint: Are ∠4 and ∠6 between the parallel lines or outside them? Are they on the same side of t?
How to solve it
  1. ∠4 is below line m and ∠6 is above line n, so both are interior (between the lines).

  3. Same-side interior angles are supplementary: ∠4 + ∠6 = 180°.

G.5-8Mastery (5)✓ Solved

I can use an informal argument to justify why an angle relationship must be true (for example, why alternate interior angles are congruent, or why the interior angles of a triangle sum to 180°).

Line ℓ goes through vertex B and is parallel to side AC. ∠1, ∠2, and ∠3 sit side by side at B.
Which argument correctly explains why ∠A + ∠2 + ∠C = 180° in every triangle?
Hint: Line AB crosses both parallel lines. Which angle pair do ∠1 and ∠A make?
How to solve it
  1. ∠1, ∠2, and ∠3 sit together on straight line ℓ, so ∠1 + ∠2 + ∠3 = 180°.
  2. AB is a transversal of ℓ ∥ AC. ∠1 and ∠A are alternate interior angles, so ∠1 = ∠A.
  3. BC is also a transversal. ∠3 and ∠C are alternate interior angles, so ∠3 = ∠C.
  4. Substitute: ∠A + ∠2 + ∠C = 180°. Nothing depended on this triangle's shape, so it is true for every triangle.

G.6-8Mastery (5)✓ Solved

I can give a proof or informal argument for the Pythagorean Theorem and explain how the converse follows from it.

Both big squares have sides a + b, and each holds the same four right triangles (legs a and b, hypotenuse c). Which argument correctly proves that a² + b² = c²?
Hint: What is the same about the two big squares? What is taken out of each one?
How to solve it
  1. Both big squares have side a + b, so they have the same area.
  2. Each one holds the same four triangles, so the same area is covered in each.
  3. Way 1 leaves one tilted square: c². Way 2 leaves two squares: a² + b².
  4. Equal areas minus equal parts leave equal areas, so a² + b² = c².
  5. The converse follows: if a triangle's sides fit a² + b² = c², it matches a right triangle with legs a and b exactly, so it has a right angle too.
