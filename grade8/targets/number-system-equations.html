What does the decimal for 411 look like?

How to solve it

  4. A repeating decimal is a rational number.

NS.1-2Approaching (3)✓ Solved

I can define rational and irrational numbers and give examples of each.

Which choice gives a correct definition of an irrational number AND a correct example?
Hint: Rational numbers can be written as a fraction of two integers. Irrational numbers can't.
How to solve it
  1. Rational: can be written as ab with integers a and b (b ≠ 0). Its decimal stops or repeats.
  2. Irrational: can't be written that way. Its decimal never ends and never repeats.
  3. √2 = 1.41421356… never ends or repeats, so it is irrational.
  4. √9 = 3, −5, and 0.333… are all rational.

Hint: Natural numbers start at 1. Whole numbers start at 0.
How to solve it
  1. Natural numbers: 1, 2, 3, … → 0 is NOT natural.
