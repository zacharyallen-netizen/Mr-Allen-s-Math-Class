EE.7-1Approaching (3)

I can identify a linear equation, recognize the role of variables, coefficients, and constants, and apply inverse operations to isolate the variable and solve a linear equation in one variable.

Try thisLook at the equation 4x − 7 = 21. Explain why it is a linear equation. Name the variable, the coefficient, and the constant on the left side. Then solve it using inverse operations.
Show answer
Answer: Linear (x has an exponent of 1); variable x, coefficient 4, constant −7; x = 7
  1. It is linear because x is only to the first power (no x², no x in a denominator).
  2. Variable: x. Coefficient: 4. Constant: −7.
  3. Undo − 7 by adding 7: 4x = 28.
  4. Undo × 4 by dividing by 4: x = 7.
  5. Check: 4(7) − 7 = 28 − 7 = 21 ✓

Show answer
Answer: A: one solution; B: no solution; C: infinitely many solutions
  1. A: the variable stayed and equals a number → one solution (x = 4).
  2. B: the variables cancelled and 0 = 6 is FALSE → no solution.
  3. C: the variables cancelled and −3 = −3 is TRUE → infinitely many solutions.

I can recognize when equations have no solution or infinitely many solutions, and mathematically determine whether a linear equation has one solution, no solution, or infinitely many solutions.

Try thisDecide whether each equation has one solution, no solution, or infinitely many solutions. Show your work. A) 4(x − 3) + 2 = 4x − 10 B) 5x − 2(x + 1) = 3x + 7 C) 6x + 1 = 2(2x − 3) + 3
Show answer
Answer: A: infinitely many; B: no solution; C: one solution (x = −2)
  1. A: 4x − 12 + 2 = 4x − 10 → 4x − 10 = 4x − 10 → −10 = −10 TRUE → infinitely many.
  2. B: 5x − 2x − 2 = 3x + 7 → 3x − 2 = 3x + 7 → −2 = 7 FALSE → no solution.

  4. Check C: 6(−2) + 1 = −11 and 2(−7) + 3 = −11 ✓

EE.7-8Mastery (5)

I can explain and justify the solution type (one, none, or infinite) with mathematical reasoning.

Try thisAva solved 2(3x − 4) + 5 = 6x − 3. The x's cancelled, so she said, "There is no solution." Is Ava correct? Explain your reasoning. Then change ONE number on the right side so the equation truly has no solution, and explain why it has none.
Show answer
Answer: Ava is wrong: it has infinitely many solutions. Example fix: 2(3x − 4) + 5 = 6x + 1 has no solution.
  1. Simplify the left: 6x − 8 + 5 = 6x − 3, so both sides are the exact same expression.
  2. Subtract 6x: −3 = −3, a TRUE statement, so every value of x works → infinitely many solutions (e.g., x = 0 gives −3 = −3).
  3. Ava's mistake: the x's cancel in BOTH special cases; you must check whether what is left is true or false.
  4. Change −3 to +1: 6x − 3 = 6x + 1 → −3 = 1, FALSE.
  5. For any x, 6x − 3 is always 4 less than 6x + 1, so the sides can never be equal → no solution.

EE.7-9Mastery (5)

I can accurately solve complex, multi-step equations and inequalities combining all problem types, and explain the meaning of a solution in the context of a real-world problem.

Try thisKai has $150 saved and adds $25 each week. Lena has $60 saved. Each week she earns $50 but spends 1/5 of it, and saves the rest. a) Write and solve an equation to find when they will have the same amount. What does your solution mean? b) Write and solve an inequality to find when Lena will have MORE money than Kai. Describe the graph and explain what it means.
Show answer
Answer: a) w = 6: after 6 weeks both have $300. b) w > 6: Lena has more starting in week 7.
  1. Let w = weeks. Lena saves (4/5)(50) = $40 per week, so Lena = 60 + 40w and Kai = 150 + 25w.
  2. a) 150 + 25w = 60 + 40w → 90 = 15w → w = 6. Check: 150 + 150 = 300 and 60 + 240 = 300 ✓
  3. Meaning: after 6 weeks Kai and Lena each have $300.
  4. b) 60 + 40w > 150 + 25w → 15w > 90 → w > 6. Graph: open circle at 6, shaded right.
  5. Meaning: Lena saves $15 more per week, so after week 6 she pulls ahead; since weeks are whole numbers, Lena has more from week 7 on.
