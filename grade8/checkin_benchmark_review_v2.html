NC.8.NS.1

Rational & Irrational Numbers

Rational = can be a fraction. The decimal stops or repeats.
Irrational = the decimal never stops and never repeats.

Rational
5   12   0.25   0.333…   √16
Irrational
π   √2   √7

Tip: Square root of a perfect square (1, 4, 9, 16, 25…) → rational. Not a perfect square → irrational.

What Is a Function?

A function gives each x only one y.

y446
Function ✓ — each x is used once. (A y can repeat.)
x112
y345
NOT a function ✗ — x = 1 goes to two y's.

Tip: Graph? Use the vertical line test: touches only once → function.
