2 Two-Step Equations

📌 TWO STEPS: Step 1 — Undo addition/subtraction. Step 2 — Undo multiplication/division.
Whatever you do to one side, do the SAME to the other

Example 1: −2x + 4 = 8

Example 2: x/2 + 6 = 7

3 Distributive Property

📌 THE RULE: Any number (or variable) outside the parentheses is multiplied by EVERYTHING inside. Pay close attention to positive/negative signs!
The 2 multiplies BOTH parts

Example: 2(2x + 3) = −6

ERROR ANALYSIS A student expands −3(x − 4) as −3x − 12. What went wrong?
A negative times a negative is positive: −3 · (−4) = +12. Correct: −3x + 12. Distribute the sign to EVERY term inside the parentheses.

4 Variables on Both Sides

📌 STRATEGY: Move variables from the RIGHT to the LEFT using inverse operations, then solve like a two-step equation.

Example: 5x + 3 = 2x + 12

5 Multi-Step Equations — The 5-Step Process

📌 THE 5 STEPS: 1. Distribute → 2. Combine Like Terms → 3. Move Variables → 4. Inverse for + or − → 5. Inverse for × or ÷

Example: −2x + 1 = 8(x + 2) − 5x

6 Special Cases — No Solution & Infinite Solutions

🔑 NO SOLUTION: Variables cancel and you get a FALSE statement (like 5 = 9).
🔑 INFINITE SOLUTIONS: Variables cancel and you get a TRUE statement (like 6 = 6).

A bar model helps you see the equation: $6 fee + $4 for each ticket = $30 total.

SHORT ANSWER Movie Theater: A movie theater charges a $6 entry fee plus $4 per ticket. If the total cost was $30, how many tickets were purchased?
Let x = number of tickets
Equation: 6 + 4x = 30
Answer: 6 tickets were purchased.
SHORT ANSWER Notebooks: A student wants to spend no more than $50 on notebooks that cost $6 each. How many notebooks can the student buy?
Let x = number of notebooks
Equation: 6x ≤ 50
“No more than” means ≤.
Answer: x must be a whole number, so the student can buy at most 8 notebooks.

D. Word Problems

1. A phone plan costs $35/month plus $0.10 per text. Last month's bill was $52. How many texts were sent?
Let x = number of texts
Equation: 35 + 0.10x = 52
Answer: 170 texts were sent.
2. Sam has $240 and saves $30/week. Jake has $420 and spends $10/week. When will they have the same amount?
Let x = number of weeks
Equation: 240 + 30x = 420 − 10x
Answer: They will have the same amount after 4.5 weeks.
3. A rectangle's perimeter is 56 cm. The length is 4 cm more than the width. Find the width.
Let x = width (cm), so the length is x + 4
Equation: 2(x + 4) + 2x = 56
Answer: The width is 12 cm.
4. Movie tickets cost $9 each. You have at most $50 to spend. What is the maximum number of tickets?
How many $9 tickets fit in $50?
Let t = tickets → 9t ≤ 50 ("at most" = ≤). Solve: t ≤ 5.56 → max 5 tickets (must be a whole number).
5. A car rental costs $45/day plus $0.25/mile. Your budget is $120 for one day. How many miles can you drive?
Let m = miles → 45 + 0.25m ≤ 120. Solve: 0.25m ≤ 75 → m ≤ 300 miles.
6. Three consecutive even integers sum to 78. Find the smallest integer.
n + (n + 2) + (n + 4) = 78
Let n = smallest → n + (n+2) + (n+4) = 78. Solve: 3n + 6 = 78 → n = 24.
