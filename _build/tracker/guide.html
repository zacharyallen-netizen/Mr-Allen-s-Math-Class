Update your Score Tracker

Adds pre-tests and unit practice to the Sheet you already use for the Fluency Lab. About 5 minutes. The web address stays the same, so nothing on the website needs to change.

Steps

  1. Go to script.google.com and open your existing Score Tracker project (the one you set up for the Fluency Lab).
  2. Click inside the code, press Ctrl + A (Mac: ⌘ + A), then Delete.
  3. Open ScoreTracker_v2_PASTE_THIS.txt, copy everything, and paste it into the empty editor. Click the disk icon to Save.
  4. In the dropdown at the top, choose setup, then press Run. If Google asks for permission, approve it (Advanced → Go to … → Allow). It may ask once more, because the script now refreshes your reports every hour.
  5. Click Deploy → Manage deployments. Click the pencil ✎ next to your Web app. Under Version, choose New version. Click Deploy.
Use "Manage deployments", not "New deployment". A new deployment makes a new web address, and the website would stop sending.

To check it worked: open the Web app URL in a browser. It should say "Score tracker v2 is running."

What you will see in your Sheet

TabWhat it shows
Scores · SummaryFluency Lab Skill Checks — unchanged.

StandardsEach student's level (1–5) on each NC standard, using your scale and your decaying average (100%, 65%, ≈42%, ≈27.5%). Website work is formative evidence — for planning, groups and conferences.
Standards (list)The same numbers, one row per student and standard, ready to sort, filter or pivot.
Statistics1 Is each pre-test trustworthy (reliability, KR-20)? 2 Which questions need a second look? 3 Are students growing since the pre-test (Wilcoxon test, effect size)?
Settings · Read MeThe cut-offs the reports use (you can change them) and a plain-words guide to every tab.

How a level is set

Pre-test (first try): Basic 3.0 met → 3; Target 4.0 also met → 4; Advanced 5.0 also met → 5. Basic not met → 2 if at least half right, otherwise 1. "Met" = 80% right.

Practice asks Target 4.0 questions: 75% right → 4, 25% → 3, 10% → 2. These cut-offs put a student on the same level as the pre-test ladder would. Practice cannot show a 5, so it never lowers an earlier 5.

Reports refresh every hour. To refresh now: in the script, choose refreshReports and press Run.

What to tell students

"At the end of a practice page or pre-test, type your first and last name and tap Send my work. You can keep working and send again." Their name is remembered on their device, and it is the same box as the Fluency Lab.
