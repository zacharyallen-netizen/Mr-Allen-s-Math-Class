UNIT 1

Equations, Inequalities & Reasoning

Go deeper: Unit 1 Notes · Unit 1 Practice
🔑 Key Idea Solve equations by undoing operations in reverse order. For inequalities, the rule is the same — except flip the sign whenever you multiply or divide by a negative number.
Variable: a letter for an unknown Equation: two expressions joined by = Inequality: uses <, >, ≤, ≥ Inverse op: the operation that undoes another Literal equation: a formula with several letters, like A = lw Exponent: the small raised number; it counts repeated factors

1.1Solving equations

An equation is like a balanced scale. Whatever you do to one side, do to the other side. Undo the steps in reverse order.

📝 Worked Example: 3x + 5 = 20

  1. Subtract 5 from both sides3x = 15
  2. Divide both sides by 3x = 5
  3. Check3(5) + 5 = 20 ✓
✓ Solution: x = 5

1.2Inequalities and the flip rule

Solve an inequality just like an equation. One new rule: if you multiply or divide by a negative number, flip the sign. Open circle = the number is not included (<, >). Closed dot = it is included (≤, ≥).

📝 Worked Example: −2x > 6

  1. Divide both sides by −26 ÷ (−2) = −3
  2. We divided by a negative, so flip > to <x < −3
  3. Check x = −4−2(−4) = 8 > 6 ✓
✓ x < −3 (sign flipped!)

📝 Worked Example 2 (no flip): 2x + 3 > 11

  1. Subtract 3 from both sides2x > 8
  2. Divide by 2 (positive — no flip)x > 4
✓ x > 4

1.3Rearranging formulas (literal equations)

A literal equation has more than one letter. To solve for one letter, undo everything around it — the same steps you use with numbers.

📝 Worked Example: solve d = rt for t

  1. t is multiplied by rd = r · t
  2. Divide both sides by rt = d ÷ r
  3. Use it: d = 120, r = 40t = 120 ÷ 40 = 3
✓ t = d ÷ r (3 hours)
🔄 Rearranging formulas:
A = lw → l = A ÷ w

1.4Exponent rules

An exponent counts repeated factors: x³ = x · x · x. When you multiply powers with the same base, add the exponents. A power of a power multiplies them.

📝 Worked Example: (x²)³

  1. Write it out(x²)³ = x² · x² · x²
  2. Add the exponentsx2 + 2 + 2 = x⁶
  3. Shortcut: power of a powermultiply 2 · 3 = 6
✓ (x²)³ = x⁶

UNIT 2

Functions & Linear Functions

Go deeper: Unit 2 Notes · Unit 2 Practice
🔑 Key Idea A function gives exactly one output for each input. A linear function has a constant rate of change. Its graph is a straight line, and its equation can always be written as y = mx + b.
Function: each input has exactly one output f(x): say “f of x” — the output when the input is x m: slope (rate of change) b: y-intercept (starting value) Δ (delta): means “change in” Slope formula: Δy ÷ Δx Slope-intercept form: y = mx + b Domain / range: all inputs / all outputs

2.1Functions and f(x) notation

Think of a function as a machine. You put in x. The rule works on it. Out comes f(x). f(4) means “the output when x is 4.”

📝 Worked Example: f(x) = 2x + 1, find f(4)

  1. Replace every x with 4f(4) = 2(4) + 1
  2. Multiply= 8 + 1
  3. Add= 9
✓ f(4) = 9, so the point (4, 9) is on the graph

2.2Slope and graphing lines

Slope tells how steep a line is: rise (up or down) ÷ run (right). The y-intercept b is where the line crosses the y-axis.

2.3Rate of change, equations, domain & range

The average rate of change is Δy ÷ Δx between two points. To write a line, put the slope m and y-intercept b into y = mx + b. The domain is every x the graph uses. The range is every y.

📝 Worked Example: f(2) = 5 and f(6) = 17

  1. Change in y17 − 5 = 12
  2. Change in x6 − 2 = 4
  3. Divide12 ÷ 4 = 3
✓ Average rate of change = 3 per 1 step in x

UNIT 3

Linear Systems

Go deeper: Unit 3 Notes · Unit 3 Practice
🔑 Key Idea A system is two (or more) equations true at the same time. The solution is the point (x, y) that satisfies every equation. Three methods: graphing, substitution, elimination.
System: set of equations solved together Solution: point where lines meet Intersection: the point where two lines cross Substitution: plug one equation into the other Elimination: add/subtract to cancel a variable Boundary line: the edge of a shaded inequality region

3.1Solving by graphing

Graph both lines. The point where they cross works in both equations. That point is the solution.

📋 How many solutions?

• Lines cross once → 1 solution
• Same line → infinitely many
• Parallel → no solution
  1. Same slope, different b?Parallel → no solution
  2. Same slope, same b?Same line → infinitely many
  3. Different slopes?They cross once → 1 solution

📊 The three cases

3.2Substitution

When one equation says “y = …”, put that expression in place of y in the other equation. Now there is only one letter to solve for.

📝 Substitution method

  1. Systemy = 2x  |  y = x + 3
  2. Substitute first into second2x = x + 3
  3. Subtract xx = 3
  4. Plug backy = 2(3) = 6
✓ Solution: (3, 6)

3.3Elimination

Line up the equations. Add (or subtract) them so one letter cancels to 0. This works because you add equal amounts to both sides.

📝 Worked Example: x + y = 10 and x − y = 4

  1. Add the equations2x = 14
  2. Divide by 2x = 7
  3. Plug into x + y = 107 + y = 10 → y = 3
  4. Check in x − y = 47 − 3 = 4 ✓
✓ Solution: (7, 3)

3.4Graphing inequalities

Graph the boundary line. Use a dashed line for < or >, and a solid line for ≤ or ≥. Test a point like (0, 0). If it makes the inequality true, shade its side.

📝 Worked Example: graph y > x − 1

  1. Boundarygraph y = x − 1 (b = −1, slope 1)
  2. Dashed or solid?> has no “equal”, so dashed
  3. Test (0, 0)0 > 0 − 1 → 0 > −1 ✓ true
  4. Shadethe side that holds (0, 0) — above the line
✓ Dashed line, shade above

UNIT 4

Sequences & Exponential Functions

Go deeper: Unit 4 Notes · Unit 4 Practice
🔑 Key Idea An arithmetic sequence adds the same amount each time (linear). A geometric sequence multiplies by the same number each time (exponential). Exponential functions describe repeated multiplication. Form: y = a · bx where a is the starting value and b is the multiplier.
Sequence: an ordered list of numbers (terms) aₙ: the nth term d: common difference (amount added) r: common ratio (number multiplied) a: initial value (when x = 0) b: base / multiplier Growth: b > 1 Decay: 0 < b < 1

4.1Arithmetic sequences

Each term adds the common difference d. To jump to any term, use aₙ = a₁ + (n − 1)d. There are (n − 1) jumps from the first term to the nth term.

📝 Worked Example: 3, 7, 11, 15, … Find a₁₀

  1. Find d7 − 3 = 4
  2. Count jumpsa₁ to a₁₀ is 10 − 1 = 9 jumps
  3. Use the formulaa₁₀ = 3 + 9 · 4 = 39
✓ a₁₀ = 39

4.2Geometric sequences

Each term multiplies by the common ratio r. Formula: aₙ = a₁ · rn − 1.

📝 Worked Example: 2, 6, 18, 54, … Find a₅

  1. Find r6 ÷ 2 = 3
  2. Count jumps5 − 1 = 4
  3. Use the formulaa₅ = 2 · 3⁴ = 2 · 81 = 162
✓ a₅ = 162

4.3Exponential functions: growth & decay

In y = a · bˣ, a is where you start and b is what you multiply by each step. If b > 1 it grows. If b is between 0 and 1 it decays (shrinks).

📝 Worked Example

  1. Evaluatey = 100 · 2³
  2. Compute power2³ = 8
  3. Multiply100 · 8 = 800
✓ y = 800

📝 Worked Example: $500 grows 4% per year

  1. Start valuea = 500
  2. Keep 100% and add 4%b = 1 + 0.04 = 1.04
  3. Write the modely = 500(1.04)ˣ
✓ y = 500(1.04)ˣ

UNIT 5

Statistics

Go deeper: Unit 5 Notes · Unit 5 Practice
🔑 Key Idea Statistics is about describing data — its center, spread, and any relationships between variables. A scatterplot makes patterns visible.
Mean: sum ÷ count Median: middle value (sorted) Range: max − min Quartiles Q1, Q3: middles of the lower and upper halves IQR: Q3 − Q1 (spread of the middle half) Outlier: a value far from the rest Scatterplot: dots on (x, y) axes Correlation: how strongly x and y move together Residual: actual − predicted

5.1Center & spread

The mean is the balance point of the data. The median is the middle value after you sort. The range shows how spread out the data is.

📝 Worked Example: data set 4, 6, 8, 10, 12

  1. Mean(4 + 6 + 8 + 10 + 12) ÷ 5 = 40 ÷ 5 = 8
  2. Range12 − 4 = 8
  3. Medianmiddle value (sorted) = 8
✓ Mean = 8 · Median = 8 · Range = 8

5.2Outliers

An outlier is far from the other data. Rule: a value is an outlier if it is more than 1.5 · IQR above Q3 (or below Q1).

📝 Worked Example: is 20 an outlier in 2, 4, 5, 6, 7, 20?

  1. Quartileslower half 2, 4, 5 → Q1 = 4 · upper half 6, 7, 20 → Q3 = 7
  2. IQR7 − 4 = 3
  3. Upper fence7 + 1.5 · 3 = 11.5
  4. Compare20 > 11.5
✓ 20 is an outlier

5.3Scatter plots, regression & residuals

A regression line ŷ (“y-hat”) predicts y from x. The residual = actual − predicted. It tells how far a point is above (+) or below (−) the line. Remember: correlation does not prove causation.

📊 Three correlation patterns

Look for the direction the cloud of points is leaning.

📝 Worked Example: ŷ = 2 + 3x. Predict y when x = 4.

  1. Replace x with 4ŷ = 2 + 3(4)
  2. Multiply, then addŷ = 2 + 12 = 14
✓ ŷ = 14

📝 Worked Example: actual y = 14, predicted ŷ = 12

  1. Residual = actual − predicted14 − 12
  2. Subtract= 2
✓ Residual = 2 (the point is 2 above the line)

UNIT 6

Quadratic Expressions & Equations

Go deeper: Unit 6 Notes · Unit 6 Practice
🔑 Key Idea Polynomials are sums of terms with variables and exponents. To simplify: combine like terms (same variable AND same exponent). To multiply two binomials: distribute every term — i.e., FOIL.

Standard form: ax² + bx + c. Factoring rewrites a quadratic as a product of two binomials, which lets you solve = 0 by setting each factor to zero.
Term: single product like 3x² Like terms: same variable + same power Distribute: a(b + c) = ab + ac FOIL: First · Outer · Inner · Last Binomial: 2 terms · Trinomial: 3 terms Quadratic: degree-2 polynomial GCF: greatest common factor Difference of squares: a² − b² Perfect square trinomial: (a + b)² Zero Product: if AB = 0, then A = 0 or B = 0

6.1Polynomial operations

Multiply every term in the first group by every term in the second. An area model keeps track: each box is one product.

📝 Combining Like Terms

  1. Original3x + 5x + 2y − y
  2. Group like(3x + 5x) + (2y − y)
  3. Combine8x + y
✓ 8x + y
📋 Distribute:
2(x + 5) = 2·x + 2·5 = 2x + 10
−3(2x − 4) = −6x + 12
⚠️ Watch the negative — distribute the sign too.

6.2Factoring — the four methods

Factoring undoes multiplying. Look for two numbers that multiply to one number and add to another. The diamond (X) organizes the search.

1️⃣ Simple Trinomial (a = 1)

x² + 5x + 6Find two numbers that multiply to 6 and add to 5
→ 2 and 32 · 3 = 6 ✓   2 + 3 = 5 ✓
✓ (x + 2)(x + 3)

2️⃣ AC Method (a ≠ 1)

2x² + 7x + 3a · c = 2 · 3 = 6
Find numbersmultiply to 6, add to 7 → 6 and 1
Rewrite + group2x² + 6x + x + 3 → 2x(x + 3) + 1(x + 3)
✓ (2x + 1)(x + 3)

3️⃣ Difference of Squares

Patterna² − b² = (a − b)(a + b)
Examplex² − 9 = x² − 3²
✓ (x − 3)(x + 3)

4️⃣ Perfect Square Trinomial

x² + 6x + 9first term: √(x²) = x · last term: √9 = 3
Check middle2 · x · 3 = 6x ✓
✓ (x + 3)²

6.3Solving quadratic equations

Get 0 on one side. Factor. Then use the Zero Product Property: if two things multiply to 0, one of them must be 0. If the equation is just x² = a number, take the square root — and remember ±.

🎯 Solving by Factoring

  1. Equationx² − 5x + 6 = 0
  2. Factor(x − 2)(x − 3) = 0
  3. Zero Product Propertyx − 2 = 0  OR  x − 3 = 0
✓ Solutions: x = 2 and x = 3

📝 Worked Example: x² = 49

  1. Take the square root of both sidesx = ±√49
  2. Both signs work7² = 49 and (−7)² = 49
✓ x = 7 or x = −7

UNIT 7

Quadratic Functions

Go deeper: Unit 7 Notes · Unit 7 Practice
🔑 Key Idea A quadratic function f(x) = ax² + bx + c makes a U-shaped graph called a parabola. If a > 0 it opens up and has a minimum. If a < 0 it opens down and has a maximum. The axis of symmetry is x = −b ÷ (2a).
Parabola: the U-shaped graph of a quadratic Vertex: the turning point (max or min) Axis of symmetry: the mirror line through the vertex Zeros (roots): where the graph crosses the x-axis y-intercept: where it crosses the y-axis (c) Vertex form: y = a(x − h)² + k, vertex (h, k)

7.1Key features of a parabola

Every parabola has a vertex, an axis of symmetry, a y-intercept, and up to two zeros. The two halves are mirror images.

7.2Graphing from standard form

Find the axis first. The vertex sits on it. Then plot a few points and mirror them across the axis.

📝 Worked Example: graph y = x² − 2x − 3

  1. Axis of symmetryx = −(−2) ÷ (2 · 1) = 1
  2. Vertex: put x = 1 in1 − 2 − 3 = −4 → (1, −4)
  3. y-intercept (x = 0)(0, −3); its mirror is (2, −3)
  4. Zeros: factor(x − 3)(x + 1) = 0 → x = 3, x = −1
✓ Vertex (1, −4), zeros −1 and 3, opens up

7.3Domain, range & comparing

The domain of every quadratic is all real numbers. The range starts or stops at the vertex’s y-value: y ≥ k if it opens up, y ≤ k if it opens down.

📝 Worked Example: Function A (graph) has a max of 5. Function B: y = −x² + 3. Which has the greater max?

  1. B opens down (a = −1)its max is at the vertex
  2. Vertex of B(0, 3) → max 3
  3. Compare5 > 3
✓ Function A has the greater maximum

7.4Building quadratic functions

Multiplying two linear expressions builds a quadratic. A rectangle’s area A = length · width is a great example.

📝 Worked Example: l(x) = x + 3 and w(x) = x. Build A(x) = l · w.

  1. MultiplyA(x) = x(x + 3)
  2. DistributeA(x) = x² + 3x
  3. Use it: x = 4A(4) = 4 · 7 = 28
✓ A(x) = x² + 3x, A(4) = 28

8.2Parallel & perpendicular lines

Parallel lines never meet, so they have the same slope. Perpendicular lines meet at a square corner (90°). Their slopes are negative reciprocals.

📐 Parallel vs. Perpendicular slopes
Parallelsame slope: m = 2 ‖ m = 2
Perpendicularnegative reciprocals: m = 2 ⊥ m = −½
Multiply perpendicular slopes → product is always −1.

📝 Line through (0, 1) parallel to y = 2x − 5

  1. Same slopem = 2
  2. (0, 1) is the y-interceptb = 1
✓ y = 2x + 1

📝 Line through (0, 1) perpendicular to y = 2x − 5

  1. Flip and change the sign2 → −½
  2. (0, 1) is the y-interceptb = 1
✓ y = −½x + 1

8.3Area on the plane

Find side lengths by subtracting coordinates. Then use the area formula. For a rectangle, A = width × height.

📝 Worked Example: rectangle with corners (1, 1), (6, 1), (6, 4), (1, 4)

  1. Width6 − 1 = 5
  2. Height4 − 1 = 3
  3. Multiply5 × 3 = 15
✓ Area = 15 square units
