1 Polynomial Operations

📌 Add/subtract = combine like terms. Multiply binomials = multiply every term by every term — an area (box) model keeps it organized.
New words. A term is a number, a variable, or a product of them, like 3x or −5. Like terms have the same variable part (2x and 7x are like terms; x² and x are not). A polynomial is a sum of terms. A binomial has 2 terms (x + 3). A trinomial has 3 terms (x² + 5x + 6). Algebra tiles show terms as shapes: a big square is x², a long strip is x, a small square is 1.

Multiply (x + 3)(x + 2)

1. Build a rectangle: x + 3 across the top, x + 2 down the side. click to reveal ✓ done
2. Count the tiles inside: click to reveal one x², five x-strips, six 1-squares
Box products: x² + 3x + 2x + 6 → click to reveal x² + 5x + 6

Subtract (2x² + 3x − 1) − (x² + 4x − 2)

Flip every sign in the 2nd ( ), then combine like terms: click to reveal 2x² + 3x − 1 − x² − 4x + 2
✓ Answer: click to reveal x² − x + 1

How to multiply two binomials with a box

  1. Write the terms of the first binomial across the top.
  2. Write the terms of the second binomial down the side. Keep each sign with its term.
  3. Multiply to fill every box.
  4. Add the boxes. Combine like terms (the two x-boxes).

2 Factoring: GCF & a = 1

📌 First pull the GCF. To factor x² + bx + c, find two numbers that multiply to c and add to b.
New words. To factor means to write a polynomial as a product (things multiplied). It is multiplying backwards. The GCF (greatest common factor) is the biggest thing that divides every term.

How to factor x² + bx + c

  1. Check for a GCF first. Pull it out if there is one.
  2. List pairs of numbers that multiply to c.
  3. Find the pair that adds to b. Watch the signs.
  4. Write (x + first)(x + second).
  5. Check: multiply back. You should get the original.

3 Factoring: a > 1 & Difference of Squares

📌 Difference of squares: a² − b² = (a + b)(a − b).
New words. A difference of squares is one square minus another square, like x² − 9. A perfect square trinomial is what you get when you square a binomial: (x + 5)² = x² + 10x + 25. For a > 1, the number in front of x² is bigger than 1, like 2x² + 7x + 3. Use the AC method: multiply a·c, then split the middle term.

Factor x² − 9

1. Write each part as a square: click to reveal x² − 3²
✓ Difference of squares: click to reveal (x + 3)(x − 3)

Factor 2x² + 7x + 3

1. a·c = 2·3 = 6. Two numbers: ×6 and +7 → click to reveal 6 and 1
Split the middle / box it: 2x² + 6x + x + 3 → click to reveal 2x(x+3) + 1(x+3)
✓ Factor out (x+3): click to reveal (2x + 1)(x + 3)

How to factor ax² + bx + c when a > 1 (AC method)

  1. Pull out any GCF first.
  2. Multiply a·c.
  3. Find two numbers that multiply to a·c and add to b.
  4. Split bx into those two x-terms. Put all four terms in a 2-by-2 box.
  5. Pull the GCF out of each row and each column. Those are the factors.
  6. Check by multiplying back.

4 Factors, Solutions & Zeros

📌 Zero-Product Property: if (x − p)(x − q) = 0 then x = p or x = q. The solutions are the zeros = the x-intercepts.
New words. The Zero-Product Property says: if two numbers multiply to 0, at least one of them is 0. A zero (or root) of a function is an x-value that makes y = 0. On a graph it is an x-intercept, where the curve crosses the x-axis. The U-shaped graph of a quadratic is a parabola.

Worked example: Solve (x − 2)(x + 5) = 0

1. Set each factor equal to 0: click to reveal x − 2 = 0 or x + 5 = 0
✓ 2. Solve each one: click to reveal x = 2 or x = −5

Worked example: A parabola has zeros −4 and 1. Write its factored form (a = 1).

1. Zero −4 → factor (x − (−4)) = click to reveal (x + 4)
2. Zero 1 → factor click to reveal (x − 1)
✓ 3. Factored form: click to reveal y = (x + 4)(x − 1)

How to solve with the Zero-Product Property

  1. Make sure one side is 0 and the other side is factored.
  2. Set each factor equal to 0.
  3. Solve each small equation. The sign flips: x − 2 = 0 gives x = +2.
  4. Check each answer in the original equation.

5 Solving Quadratics

📌 No x-term (like x² = 25) → square roots (±). A trinomial = 0 → factor, then zero-product.
Why ±? Both 7 · 7 and (−7)(−7) equal 49. So x² = 49 has two answers: x = 7 and x = −7. We write x = ±7 (“plus or minus 7”).

How to solve by square roots

  1. Get the squared part alone on one side (like x² = 49).
  2. Take the square root of both sides.
  3. Write ± in front. There are two answers.
  4. Check both answers.

6 Revealing Features

📌 Factored form shows the zeros. The vertex’s x-value is the midpoint of the zeros.
New words. The vertex is the turning point of a parabola (lowest or highest point). The axis of symmetry is the vertical line through the vertex. The two sides of the parabola are mirror images across it.

Try it: move the sliders for y = a(x − h)² + k. Watch the vertex, the axis and the zeros.

y = (x + 1)(x − 3): find the vertex

Zeros −1 and 3 → axis x = midpoint: (−1 + 3)/2 = click to reveal x = 1
Plug in x = 1: (1+1)(1−3) = (2)(−2) = click to reveal −4
✓ Vertex: click to reveal (1, −4)

How to find the vertex from factored form

  1. Read the zeros from the factors (flip the signs).
  2. Add the zeros and divide by 2. That is the axis of symmetry, x = h.
  3. Plug h into the function to get y.
  4. Write the vertex as (h, y).

7 Completing the Square

📌 x² + bx needs one more piece to become a perfect square: add (b ÷ 2)². Then x² + bx + (b ÷ 2)² = (x + b ÷ 2)².
New words. Completing the square means adding the missing corner so the tiles make a full square. Whatever you add to one side of an equation, add to the other side too.

Try it: change b and watch the missing corner.

Worked example: Solve x² + 6x − 7 = 0 by completing the square.

1. Move the number to the right side: click to reveal x² + 6x = 7
2. Half of 6 is 3. Square it. Add to both sides: click to reveal x² + 6x + 9 = 7 + 9 = 16
3. Write the left side as a square: click to reveal (x + 3)² = 16
4. Take ± square roots: click to reveal x + 3 = ±4
✓ 5. Subtract 3: click to reveal x = 1 or x = −7

How to complete the square (when a = 1)

  1. Move the constant to the right side.
  2. Take half of b. Square it.
  3. Add that number to BOTH sides.
  4. Write the left side as (x + half of b)².
  5. Take ± square roots. Then solve for x.

8 The Quadratic Formula

📌 For ax² + bx + c = 0:
x = −b ± √b² − 4ac2a
The formula works for every quadratic, even ones that do not factor.
New words. Standard form is ax² + bx + c = 0 (everything on one side, 0 on the other). The discriminant is b² − 4ac, the part under the square root. It tells how many real solutions there are: positive → 2, zero → 1, negative → 0.

Each discriminant is computed from that parabola’s own a, b and c.

Worked example: Solve 2x² + 3x − 2 = 0 with the formula.

1. Read a, b and c (keep the signs): click to reveal a = 2, b = 3, c = −2
2. Discriminant b² − 4ac: click to reveal 3² − 4(2)(−2) = 9 + 16 = 25
3. Put it in the formula: click to reveal x = (−3 ± √25) ÷ (2 · 2) = (−3 ± 5) ÷ 4
✓ 4. Split the ±: click to reveal x = 2 ÷ 4 = ½ or x = −8 ÷ 4 = −2

How to use the quadratic formula

  1. Write the equation in standard form: ax² + bx + c = 0.
  2. Write down a, b and c with their signs.
  3. Find the discriminant b² − 4ac. Use parentheses for negatives: (−6)² = 36.
  4. Put the numbers in the formula.
  5. Do the + answer and the − answer separately.
