Ordered pair

Solution

System of equations

📌 A point is a solution if it makes the equation true — that is, if it lies on the line. The graph shows every solution.

2 Solving by Graphing

📖 Words to know
Intersection
— the point where two lines cross. Both lines go through it.
Slope-intercept form
— y = mx + b. The slope is m (rise over run). The y-intercept is b (where the line crosses the y-axis).
Parallel
— lines that never cross. They have the same slope.
📌 The solution to a system is the intersection point — where the lines cross.
One solution: lines cross
No solution: parallel
Infinitely many: same line

3 Substitution

📖 Words to know
Substitute
— swap in. Replace a letter with something that is equal to it.
Isolated
— alone on one side, like y in y = 2x.
Back-substitute
— put the number you found back in to get the other letter.
📌 When one variable is alone, substitute its expression into the other equation.
Bar model: y = 2x means y is two x-bars. So x + y is three x-bars, and they make 9.

4 Elimination & Why It Works

📖 Words to know
Coefficient
— the number in front of a letter. In 3x, the coefficient is 3. In −y, it is −1.
Opposites
— numbers that add to 0, like 2 and −2.
Eliminate
— get rid of. Adding opposites makes a letter cancel (disappear).
📌 Adding equal quantities to both sides keeps equality — that’s why elimination produces the same solution. Line up the system so one variable cancels.
Two balanced scales. Put both left sides together and both right sides together. It still balances!

🪜 Steps: elimination
  1. Line up the equations: x-terms, y-terms, =, numbers.
  2. Look for opposite coefficients, like +y and −y.
  3. None? Multiply one equation by a number to make opposites. Multiply EVERY term, even the number after =.
  4. Add the equations. One letter cancels.
  5. Solve for the letter that is left.
  6. Put it back into an original equation. Find the other letter.
  7. Write (x, y). Check it in both equations.

5 Choosing a Method

📖 Words to know
No solution
— the lines are parallel. They never meet.
Infinitely many solutions
— both equations make the same line. Every point on it works. "Infinitely many" means too many to count; it never ends.
📌 Pick the most efficient tool for the system in front of you.
How to choose: substitution, elimination, or graphing
When you compare…PictureNumber of solutions
Different slopeslines crossOne
Same slope, different bparallel linesNone (the algebra ends with something false, like 3 = −1)
Same slope, same bthe same lineInfinitely many (the algebra ends with something always true, like 8 = 8)

🪜 Steps: how many solutions?
  1. Write both equations as y = mx + b.
  2. Compare the slopes (m). Different? One solution.
  3. Same slope? Compare b. Different b means parallel: no solution.
  4. Same slope AND same b means the same line: infinitely many solutions.

6 Graphing Inequalities & Systems

📖 Words to know
Inequality
— a math sentence with <, >, ≤ or ≥ instead of =.
Boundary line
— the line y = mx + b. It splits the graph into two sides.
Half-plane
— one side of the boundary line. We shade the side that works.
Test point
— a point you try, like (0, 0), to see which side to shade.
📌 Boundary line: solid for ≤ or ≥, dashed for < or >. Shade the side that makes it true; for a system, the solution is the overlap.
Symbol (y alone on the left)LineShade
y < mx + bdashed - - -below
y ≤ mx + bsolid ——below
y > mx + bdashed - - -above
y ≥ mx + bsolid ——above

🪜 Steps: graph an inequality
  1. Get y alone.
  2. Graph the boundary line y = mx + b.
  3. Use a solid line for ≤ or ≥. Use a dashed line for < or >.
  4. Pick a test point that is not on the line. (0, 0) is easiest.
  5. Put it in. True? Shade its side. False? Shade the other side.
  6. For a system, do this for each inequality. The answer is where the shadings overlap.
