1 What Is a Function?

Input:
the number you put in (usually x).
Output:
the number you get out (usually y).
Relation:
any set of input–output pairs.
Function:
a relation where each input has exactly ONE output.
Mapping diagram:
a picture with arrows from each input to its output.
📌 A function gives exactly one output for each input. (No input may map to two different outputs.)
Input x goes in, the rule f produces one output f(x)
Function. Each input has one arrow. (Two inputs may share an output.)
Not a function. Input 2 has two arrows.

Vertical line test: a graph is a function if no vertical line crosses it more than once.

Vertical line test — slide the gold line

How to decide if a relation is a function

  1. List the inputs (x-values).
  2. For each input, count its outputs.
  3. Any input with two or more different outputs? Then it is NOT a function.
  4. Outputs may repeat. That is OK.
  5. On a graph, use the vertical line test.

2 Function Notation

f(x):
read “f of x.” It means the output of function f when the input is x. It does NOT mean f times x.
Evaluate:
put a number in for x and find the output.
📌 f(x) is the output for input x. f(3) means “evaluate at x = 3.” The statement f(3) = 7 reads “the input 3 gives output 7.”
f(4) = 9 means input 4, output 9. On the graph that is the point (4, 9).

  3. Write the answer as f(a) = ____.

3 Graphing Linear Equations

Slope (m):
how steep a line is. Slope = rise ÷ run.
Rise:
how far up (+) or down (−) you move.
Run:
how far right you move.
y-intercept (b):
where the line crosses the y-axis. The point is (0, b).
Slope-intercept form:
y = mx + b.
📌 Slope-intercept form y = mx + b: b is the y-intercept (start), m is the slope = rise/run (rate).
Move m and b. Watch the line change.
y = 2x − 3 : start at (0,−3), then up 2 / right 1

How to graph y = mx + b

  1. Plot b on the y-axis. That is the point (0, b).
  2. Write the slope m as a fraction: rise over run. (2 = 2/1.)
  3. From (0, b), move up the rise (down if it is negative). Then move right the run. Plot a point.
  4. Do it once more to get a third point.
  5. Draw a straight line through the points, with arrows on both ends.

4 Key Features of Linear Functions

x-intercept:
where the graph crosses the x-axis. There, y = 0.
y-intercept:
where the graph crosses the y-axis. There, x = 0.
Increasing:
the graph goes up as you read left to right.
Decreasing:
the graph goes down left to right.
Constant:
the graph is flat.
📌 y-intercept: crosses the y-axis (x = 0). x-intercept: crosses the x-axis (y = 0). Increasing if slope > 0, decreasing if slope < 0.
y = −x + 4 : y-int (0,4), x-int (4,0), decreasing
Slope > 0: increasing. Slope < 0: decreasing. Slope = 0: constant.

How to find intercepts from an equation

  1. y-intercept: put x = 0 and find y. Write (0, y).
  2. x-intercept: put y = 0 and solve for x. Write (x, 0).
  3. Check: both points should be on the graph.

5 Domain & Range

Domain:
all the inputs (x-values). Read the graph left to right.
Range:
all the outputs (y-values). Read the graph bottom to top.
Discrete:
separate dots, with gaps (like whole tickets).
Continuous:
an unbroken line (like time or distance).
Interval notation:
[a, b] means a ≤ x ≤ b. A round bracket ( ) means the end is NOT included.
📌 Domain = all inputs (x-values). Range = all outputs (y-values). Discrete = separate points; continuous = unbroken line.
The gold bar on the x-axis is the domain. The gold bar on the y-axis is the range. Closed dots mean the ends are included.
Tickets: discrete (whole tickets only, so separate dots). Gas: continuous (any amount of gas, so a solid line).
In context, pick a reasonable domain — for example, time can’t be negative, and people must be whole numbers.

How to find domain and range from a graph

  1. Domain: find the leftmost x and the rightmost x.
  2. Range: find the lowest y and the highest y.
  3. Closed dot → use ≤. Open dot → use <.
  4. An arrow means the graph keeps going forever in that direction.
  5. Write smallest first: a ≤ x ≤ b.

6 Average Rate of Change & Parameters

Δ (delta):
means “change in.” Δy is the change in y.
Average rate of change:
how much the output changes for each 1 unit of input, between two points.
Parameter:
a number in the rule, like m and b in y = mx + b. Changing it changes the graph.
📌 Average rate of change = Δy/Δx = (f(b) − f(a))/(b − a). For a line, that’s the slope. In context: slope = rate, intercept = starting value.

How to find an average rate of change

  1. Find the two points: (a, f(a)) and (b, f(b)).
  2. Δy = f(b) − f(a). (Output change.)
  3. Δx = b − a. (Input change.)
  4. Divide: Δy ÷ Δx.
  5. Say it with units: “___ per ___.”

f(2) = 5 and f(6) = 17. Find the average rate of change.

Δy / Δx: (17 − 5) / (6 − 2) = click to reveal 12 / 4
✓ Rate = click to reveal 3
